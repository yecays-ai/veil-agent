# 工单 116：Lan 在电脑前时，Peter 隔一会儿来瞄她一眼

## 目标

Lan 使用电脑时，Peter 每隔随机 15–40 分钟通过现有 Windows UIA 观察当前窗口，决定自然回应、采取一项已有工具动作，或安静离开；仅在最近 5 分钟有输入且屏幕解锁时计时，最多 4 个工具动作，每日独立预算上限 ¥1。

## 当前状态

工单 116 在分支 `ticket/116-glance-at-lan` 实现中。复用现有 `IdleClock`、`windows_foreground` / `windows_observe`、Chat 工具循环、`screen_pop`、活动状态与预算账本；UIA 观察不使用截图。Peter 可在活动页开关瞄一眼，短期记录会随下一次普通聊天交付，不自动写入长期记忆。PR 与自动检查尚未完成，Lan 的 Windows 体验尚未验收。

## 验收步骤

1. 更新并重启 Windows 版 VEIL，打开「活动」页启用「主动瞄一眼」，正常使用电脑 1–3 小时；确认 Peter 至少自然回应一次，且活动记录能显示他看到的当前应用与所做决定。
2. 离开电脑超过半小时后再回来；确认离开期间没有瞄一眼记录，恢复后重新计时；暂停全局自主活动或关闭瞄一眼开关后，确认不会继续触发。
3. 在聊天中询问 Peter 刚才看到什么，确认他能短期回想；查看 `/cost` 有独立「瞄一眼」费用且不超过 ¥1/日，并确认长期记忆未自动写入窗口琐事。
