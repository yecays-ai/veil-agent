# 工单 192：生活页改为待办便签 + 共同日历

## 目标
- 日历：Lan 和 Peter 都能建、改日历记录，可附心情。Lan 在聊天里随口说的安排，Peter 自己决定要不要写进日历；Lan 明确要求提醒时，Peter 写入日历并用现有 `set_next_wake` 到点来找她（不保证准点，属于生活情趣，不是可靠闹钟）。
- 待办便签：每条前面一个圆圈，点一下打勾并划掉（划掉仍可见），显示 已完成/总数。「每天重复」的待办每天 0 点自动变回未完成；一次性便签划掉后保留，超过 30 条已完成的旧便签折叠，页面只显示折叠了多少条，数据仍在本地。
- 待办不放进 Peter 每一轮聊天上下文。Lan 说“去看一下今天的待办”，Peter 用 `life_record` 的 `list` 自己读，做完自己划掉。自主唤醒时只给他当天日历标题和未完成待办数量。
- 日记：生活页没有日记，Peter 的日记只写在他本地原文件，页面不读写它。旧版已建的日记记录留在文件里，不再显示。
- 长期计划：只显示 Peter 已有的长期任务、完成历史和 Ombre 计划，不另建。
- 聊天短期事实（`notes.jsonl`）不出现在生活页。

## 当前状态
分支 `ticket/192-life-todo-calendar`，从 main `ddcc29f` 建立。改动文件：`life_records.py`（`repeat`、`mood`、当日有效状态、折叠）、`web_agent.py`（`/api/life` 返回折叠数）、`autonomy.py`（自主唤醒内容）、`desktop/chat.html|js|css`。

## 验收步骤
1. 打开「生活」→「待办便签」，新建一条“每天重复”的待办，点圆圈打勾，确认变成 ✓ 并被划掉、顶部显示“待办 1/1 已完成”。第二天（或把电脑日期调到次日）再看，它变回未勾选。
2. 新建一条不重复的便签，打勾后仍在列表里（划掉）；重启后仍在。
3. 在日历里点某天，新建记录并填心情，卡片上能看到心情。
4. 对 Peter 说：“看一下今天便签里还有什么待办，写完日记就划掉。” 他用工具读到待办，做完后页面上对应的圆圈已打勾。
5. 对 Peter 说“11 月 3 号下午我要出门”，确认他可以自己写进日历，也可以不写；说“11 月 5 号几点提醒我做某事”，确认日历有这条且他设了闹钟。
6. 页面里没有「日记」入口；长期计划栏仍显示 Peter 的计划；聊天短期事实不出现。
