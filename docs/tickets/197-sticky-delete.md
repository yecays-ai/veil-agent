# 工单 197：待办便签可删除，每日重复单独一张

## 背景
Lan 验收 193 时发现：每日重复的事和一次性待办混在同一张便签里；写错或重复的条目没有任何地方可以删除；便签顶部的“胶带”条不居中，输入框被横线穿过。

## 改动
- 每日重复的待办单独放在最上面一张「每日重复」便签，自带输入框（回车即添加为每日重复）；一次性待办按日期各一张，输入框只加一次性待办。
- 每条待办右侧有 ×（点一次变成“确认删除”，再点才删，3 秒不点自动取消）；详情面板也有「删除」按钮。只有 Lan 能删，只能删日历记录和待办便签，长期计划等来源记录不可删。
- 删除前会把原记录存进 `life-records-deleted.jsonl`（不显示，只留底）。
- 顶部改成通栏纯色色片，去掉横格线，输入框不再被线穿过。

## 验收（Lan）
update.bat 后打开生活页：每日重复的事在最上面那张；点 × 两次删掉一条；详情面板里也能删。
