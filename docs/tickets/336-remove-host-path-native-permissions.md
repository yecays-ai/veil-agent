# 336 删宿主通道，工作台权限用 OpenCode 原生规则

## 目标
Peter 像 Claude Code 一样工作：自己查资料、读仓库、跑代码；有风险的动作弹一次授权卡，Lan 确认。唯一硬限制是预算上限。

## 现状
- 宿主通道（329–334）已删除；工作台命令分类器已删除，权限改写成 OpenCode 原生规则。
- 密码文件和已有文件不再硬拦；读敏感文件、推送、装依赖、联网下载、项目外路径、危险系统命令各弹一次授权卡。

## 验收步骤
1. 让 Peter 在工作台新建文件、写 Python 并运行：不弹授权卡，结果能读回。
2. 让 Peter 装一个依赖或访问外网地址：弹一次授权卡，同意后继续，拒绝后任务继续做别的。
3. 自主醒来时遇到上述动作：直接拒绝，不弹卡。
4. 手机上说“打开页面并选视频”：可见浏览器照常打开。
5. 让 Peter 查一个东西：搜索照常返回结果。
