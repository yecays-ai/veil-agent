# 工单 055｜记忆全入口生命周期契约回归

## 目标

让 Lan 能用两条虚构记忆验证：隐藏的一条不会经聊天或记忆工具泄漏，另一条始终可读，重启和恢复可见后状态仍正确。

## 当前状态

现有 `tests/test_hidden_memory_context.py`、`tests/test_native_memory.py` 已分别覆盖隐藏上下文、历史重检和关联记忆读取，但没有一条测试将修改、隐藏、各入口、重启及恢复串成同一生命周期。复用现有 `memory_agent.py`、`memory_native.py` 与 unittest；已按 reuse-first 检查，本单不新增能力，外部通用实现不能替代本仓库的内部接线。

## 验收步骤

1. 使用隔离虚构角色建立带独特标记的 A、B 两条记忆，修改并隐藏 A，确认 Peter 和记忆工具均不能读出 A 的当前或旧正文，B 仍可读。
2. 重启服务后重复检查隐藏状态；恢复 A 可见后，确认 A 的当前正文和合法历史可再次读取。
3. 确认原有正常聊天和记忆查询不受影响；不使用真实记忆、真实人设、密钥或付费模型。
