# 工单 128 新对话的开场记忆

## 目标

Peter 开始新对话时让开场记忆浮现一次，继续聊天时仍能按话题回忆。

## 当前状态

复用 Ombre 的 breath 与现有自动检索；旧实现将启动时取得的开场记忆注入每轮。新对话重新获取开场记忆，只在首次正常回复时附上；自主活动、连续聊天以及重启已有对话不重复注入。长期记忆、聊天和短期便签不迁移。

## 验收步骤

1. 开始新对话，聊几句不同话题；检查首轮带入开场记忆，后续不再无条件反复带入。
2. 在之后的聊天中主动问起共同经历，确认相关记忆仍可按话题找回；重启后继续原对话不重新当作新对话。
3. 观察真实聊天的自然度，同时核对旧聊天、短期便签和长期记忆仍在。
