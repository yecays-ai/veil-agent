# 397 Peter 页清理与待批准队列

#396 修好接口后，还剩两个问题：

1. **Peter 页**：每块下面写了解释文字；顶部 sticky 标题透明，滚动时压住正文；按钮太长。
2. **自主活动的“待审批”你看不见**：以前只有聊天里临时弹的审批卡片；自主活动遇到需要 Lan 批准的动作，只写一条“被拒绝”，你回来没有入口处理。

## 页面修复

- 删掉每块下面的解释段落；说明只放在标题的 ⓘ 悬浮提示里。
- 标题改普通流式，不再 sticky，不再重叠。
- 按钮统一「保存」「新增」；保留历史版本/恢复。
- 保持 #396 的单层分栏，不再卡片套卡片。

## 待批准队列

- 新增 `PendingApprovals`：`data/<角色>/pending-approvals.json`，持久保存，重启不丢。
- 自主活动里需要批准的动作：记录一条 pending（原文、时间、过期时间），本轮不执行、不重试；返回仍是 `not asked`。
- 你回来能在两处看到同一份记录：
  - 右侧栏「等待处理」：有 N 件需要你决定；
  - 活动页顶部「需要你决定」卡片：原文 + 请求/过期时间 + 「同意一次 / 拒绝」。
- 同意/拒绝写回同一份；重启后还在。
- 下一次醒来，Peter 看到 `APPROVALS FROM LAN`：pending / approved / denied；同意后他只做被批准的那件事，拒绝/过期不再重试。
- 不自动执行、不放开权限；只是把“请求你批准”变得可见、可处理。

## 验收

1. 自主里触发需要批准的动作，不再只留一条红字；活动页/右侧栏出现待处理。
2. 你点同意/拒绝后，两处同步消失；重启后状态还在。
3. 下一次醒来，Peter 看到 approved/denied，不会重复撞。
4. Peter 页滚动时标题不盖正文，没有解释段落，按钮是「保存」。
