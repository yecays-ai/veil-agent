# 工单 005g：手动删除记忆

## 背景

lan 2026-10-19：旧的重复记忆不能自己删，只能 `/forget` 隐藏。她在手机版 VEIL 里的规则是“删除就是忘记”，希望以后自己清理记忆库，不再让 agent 代为清理。

## 做什么

- `/delete 编号`：只显示这条的编号和标题，并提示再输入 `/delete 编号 确认`；不按时间或猜测批量删，一次只删一条、只删点名的编号。
- 确认后：先在本机状态里标记为已删除并隐藏（即使 Ombre 没应答，也不再被想起、不再给补记看、不再出现在 `/memory`），再调 Ombre 的 `trace(bucket_id, delete=True)`。
- Ombre 对普通记忆只提供软删除（桶仍留在记忆目录里，不彻底擦除；彻底擦除只允许清理标了测试数据的桶，这是读它源码得到的）。本程序也不提供 `/restore` 恢复已删除的记忆。
- Ombre 没确认删除时提示一句，该条仍保持不被想起，可再试。
- 删除不擦掉最近聊天原文：还在近期原文里的内容仍可能被提到。

## 不做

不批量删除、不按相似度自动删、不自动清理旧重复条目。
