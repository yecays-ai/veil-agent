# 工单 313：OpenCode 工作台任务范围授权

## 目标

Peter 在隔离项目内完成读取、修改、测试和修复时连续执行；安装、联网、凭据、发布和范围外操作继续由 Lan 明确批准。

## 当前状态

OpenCode 以 `bash: ask` 把命令交给 VEIL 的审批桥。现有桥只预扫描任务启动前已有的命名 Python 测试脚本，并以单条命令作为批准复用键；它没有本次项目范围或任务中已创建测试的状态。工作台已具备实际项目选择、快照、Docker 隔离、预算、停止和审批结果回传。OpenCode 原生权限规则只用于转发，VEIL 继续是最终裁决层。参考 OpenCode 的公开权限文档和源码，只复用其 `ask/allow/deny` 请求接口；不引入依赖，也不依赖其规则来保护 VEIL 的边界。

## 验收步骤

1. 在工作区的计算器项目中要求 Peter 增加取模、修改代码并反复运行测试；全过程不为项目内读取、修改、子目录或常规测试重复审批。
2. 让 Peter 在工作区中新建一个简单 Python 项目、写测试并运行；新测试脚本不需要在任务开始前存在。
3. 让 Peter 在隔离测试项目准备 MCP 接入；安装或联网时卡片说明项目和操作范围，批准后同一范围内继续，拒绝后明确告知并停止该外部操作。
