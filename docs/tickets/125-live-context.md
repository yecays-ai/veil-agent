# 工单 125｜实时上下文窗口

## 目标
Lan 能单独看到 Peter「现在脑子里带着什么」：每次回复带进了哪些上下文、用了哪些工具，以及当前挂着的短期便签。和活动流水分开，上下两块，可以拖出成独立小窗。

## 现状
- `data/<角色>/context-log.jsonl`（工单 121）每次请求记一行大小与命中数；`tools.jsonl` 记工具调用，二者用 request_id 对应。
- `data/<角色>/notes.jsonl`（工单 123）记短期便签的追加状态。
- 本工单把两者整理后随 `/api/events` 下发，桌面新增「上下文」页渲染；只读，不触发提取。

## 验收（Lan 在 Windows 上）
1. 退出 Peter，运行 update.bat，重新打开，导航栏出现「上下文」。
2. 和 Peter 聊一句：上半块「聊天时活动」出现这次请求，显示原文轮数、背景段、长期记忆、便签条数，以及他用的工具（如 send_message ×2）。
3. Peter 开着满 30 分钟且聊过天后：下半块出现便签，进行中的显示约几点淡出；完成或过期的灰显保留 3 小时。
4. 把「上下文」标签拖出成独立小窗，内容同样实时更新；点「合并回主窗口」能回去。
