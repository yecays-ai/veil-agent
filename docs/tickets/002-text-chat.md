# 工单 002：文字聊天，重启后接得上

对应重建计划阶段一 · 大块 1。

## 目标

lan 在 Windows 上双击启动，和 Peter 用中文文字聊天；关掉再打开，问“我们刚才聊到哪了”，他能说对。

## 当前状态

- 仓库只有协作文件，没有程序代码。
- 已定：Python；Peter 先用 DeepSeek（OpenAI 兼容接口，配置里一行可换 GPT）；花费上限 ¥10/天、¥300/月，不设请求次数上限。

## 范围

1. **角色是配置**：`characters/<id>/` 下放角色配置（名字、模型、接口地址、人设文件路径）。真实人设只放本机 `persona/*.md`（已在 `.gitignore`），仓库只提交 `*.example.md`。人设文件读不到就不启动，提示一行原因，不用空人设开口。
2. **模型调用**：用官方 `openai` Python 包调 OpenAI 兼容接口，不自己写 HTTP 客户端，不做多供应商框架。API Key 只从本机 `.env` 读。
3. **聊天记录落账**：每个角色一个只追加的 JSONL，每条带时间、说话人、原文。这是“发生过什么”的唯一依据，以后的记忆补记也从这里取。不写工具结果以外的推断。
4. **重启接得上**：启动时读回该角色最近 N 轮（默认 20 轮，可配置）原文放进上下文，屏幕上一行说明“接上了 N 轮”。没有旧记录就正常开始。
5. **花费有底、看得见**：价格写在配置里；每次请求前先按上限检查，超了就不发，提示一行；每次请求后按接口返回的 token 用量记账。一个命令查今天和本月花了多少。失败不自动重试。
6. **Windows 好用**：双击 `start.bat` 启动；中文输入输出正常；Ctrl+C 能干净退出，已显示的回复和记录不丢。
7. **测试**：只用假模型，不调付费接口。覆盖：落账与读回、超预算不发请求、人设缺失不启动、Ctrl+C 不丢记录。

## 不做

记忆（Ombre）、工具、语音、主动发消息、图形界面。这些在后面的工单。

## 验收（lan 在 Windows 上做）

1. 双击 `start.bat`，和 Peter 聊几句，随口提一件自己的事。
2. 关掉窗口，再双击打开，屏幕显示接上了几轮。
3. 问“我们刚才聊到哪了”，他能说对；输入查花费的命令，能看到今天花了多少。
