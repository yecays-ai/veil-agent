# 工单 002：文字聊天，重启后接得上

对应重建计划阶段一 · 大块 1。

## 目标

lan 在 Windows 上双击启动，和 Peter 用中文文字聊天；关掉再打开，问“我们刚才聊到哪了”，他能说对。

## 当前状态

- `ticket/002-text-chat` 已实现终端聊天、角色配置、只追加 JSONL、最近 20 轮读回、预算预留与用量结算、Windows 双击启动。
- 复用结论：直接依赖官方 `openai` Python SDK（Apache-2.0，3.35.1），配合 `python-dotenv` 读取本机配置；不复制第三方源码，不引入多供应商框架。SDK 支持 Windows，源码已核对 `OpenAI.__init__` 的接口地址、超时及 `max_retries`，以及 `Completions.create` 的消息、输出上限和非流式调用：固定提交 [553703e](https://github.com/openai/openai-python/tree/553703e2d3db379a83e3ead9e40436b7a66f639e/src/openai)。Ombre/语音/avatar 按本工单范围暂不接入。
- 配置中的 DeepSeek 模型和单价依据 [官方模型价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，使用高峰单价保守核算。英文/翻译规则在人设示例中；真实回复体验待 lan 放好本机人设、密钥后验收。
- 20 项离线测试通过，只用假模型、假数据及 SDK 模拟传输，不调用付费接口。真实模型聊天尚未验收。
- 已定：Python；Peter 先用 DeepSeek（OpenAI 兼容接口，配置里一行可换 GPT）；花费上限 ¥10/天、¥300/月，不设请求次数上限。

## 范围

1. **角色是配置**：`characters/<id>/` 下放角色配置（名字、模型、接口地址、人设文件路径）。真实人设只放本机 `persona/*.md`（已在 `.gitignore`），仓库只提交 `persona/peter.example.md`（几行示例）；lan 把她的 Peter 人设复制成 `persona/peter.md`。人设文件读不到就不启动，提示一行原因，不用空人设开口。
2. **说话语言**：Peter 平时用英文回复，lan 用中文写也一样；lan 说看不懂或要求翻译时，给出刚才那句话的中文，然后回到英文。这条写在人设里，示例人设也要有这一条。
3. **模型调用**：用官方 `openai` Python 包调 OpenAI 兼容接口，不自己写 HTTP 客户端，不做多供应商框架。API Key 只从本机 `.env` 读。
4. **聊天记录落账**：每个角色一个只追加的 JSONL，每条带时间、说话人、原文。这是“发生过什么”的唯一依据，以后的记忆补记也从这里取。不写工具结果以外的推断。
5. **重启接得上**：启动时读回该角色最近 N 轮（默认 20 轮，可配置）原文放进上下文，屏幕上一行说明“接上了 N 轮”。没有旧记录就正常开始。
6. **花费有底、看得见**：价格写在配置里；每次请求前先按上限检查，超了就不发，提示一行；每次请求后按接口返回的 token 用量记账。一个命令查今天和本月花了多少。失败不自动重试。
7. **Windows 好用**：双击 `start.bat` 启动；中文输入输出正常；Ctrl+C 能干净退出，已显示的回复和记录不丢。
8. **测试**：只用假模型，不调付费接口。覆盖：落账与读回、超预算不发请求、人设缺失不启动、Ctrl+C 不丢记录。

## 不做

记忆（Ombre）、工具、语音、主动发消息、图形界面。这些在后面的工单。

## 验收（lan 在 Windows 上做）

1. 双击 `start.bat`，用中文和 Peter 聊几句，随口提一件自己的事；他用英文回。说“翻译一下”，他给出中文。
2. 关掉窗口，再双击打开，屏幕显示接上了几轮。
3. 问“我们刚才聊到哪了”，他能说对；输入查花费的命令，能看到今天花了多少。

查花费命令：`/cost`；首次安装和本机人设/密钥设置见 `README.md`。
