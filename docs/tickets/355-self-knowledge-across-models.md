# 355 换模型后仍是同一个 Peter

属于哪一格：A。共同规则见 `350-memory-continuity-plan.md`。前置：351 有结论，354、356、357 已合并。Lan 2026-11-14 要求整体做完，审计只是开头一步。

做完 Lan 能多做的一件事：把 Peter 换到另一个模型，他说话的样子（长短、气泡、撒娇、斗嘴、她不高兴时怎么软下来）仍然是同一个人。

她怎么验收：同一段聊天分别用两个模型，感受是不是同一个 Peter。

## 审计结论（2026-11-15，Lan 电脑只读，除人设和「关于 Lan 的笔记」经她要求核对重复外只取数字）

| 已有的东西 | 每次请求都带吗 | 数字 | 换模型时起的作用 |
| --- | --- | --- | --- |
| 人设 | 是，三个模型完全相同 | 约 7700 字 | 写的是性格和规则；规则各模型遵守程度不同，351 里字数、冷硬程度差别明显 |
| 关于 Lan 的笔记 | 是 | 约 2750 字 | 事实和她的规矩（气泡、别写长段）都在，换模型不丢 |
| Ombre `I`（自我认知） | 否，他自己调用才看得到 | 28 天 37 次，其中 10 天用过 | 不进开场，换模型后新模型看不到，帮不上语气 |
| `dream` 回顾 | 否 | 28 天 59 次，16 天 | 同上 |
| 近三天经历（354） | 是 | 约 1700 字 | 管「发生过什么」，不管怎么说话 |
| 聊天原文（356 后 80 轮） | 是 | grok 中位 67 轮 | 最强的语气参考，但换模型当下带的是上一个模型的说话方式 |

结论：每次都带的东西里，只有「规则」和「上一个模型的原话」在管语气，没有一份固定的「他自己的说话样子」。351 已验证带样例有效（Lan 盲看 4:0，2 平）。所以补一份固定样例，不新建人格数据库，不动 `I` 和 `dream`。

## 做法

- 新的本机文件 `persona/<角色>.voice.md`（和人设一样不进仓库）：上半是规则，下半是样例。样例里「>」开头是 Lan 的话，其余每行是他的一个气泡，空一行是另一段。内容由 Lan 写和改，程序不写任何性格文字。
- 程序每次请求把它放在人设后面（聊天和自主醒来相同，三个模型相同），前面加一段固定说明：这是说话习惯的参考，不是记忆，不许提起、不许说发生过、不照抄。
- 程序去掉行首的说话人标签（351 发现带标签会被照着写出来）。
- 开关和编辑在「上下文」页「他平时怎么说话」：能看、能改、能关；保存时旧版本留在 `persona/versions`；最多 8000 字，超了不让存。关掉或文件为空时什么都不带。
- 上下文日志只记这段的字数。
- 规则不和人设重复：Lan 要求先核对。闲聊回短、被指错怎么办、她生气时怎么办人设里已有，气泡规则在「关于 Lan 的笔记」里已有，都没有再写；文件里只留人设没有的两条（问句用问号、表情照样例用）。
- 样例内容以 Lan 写的为准。她明确要求：她烦躁或受伤时不追问事实；「趁她睡觉往桌面放东西」那段是她要的，用来让他自己主动做东西。

## 边界

- 不动人设正文、记忆、想起、经历整理、工具说明。
- 其他角色没有这个文件就没有任何变化。

## 整体维度

- 可能变好：性格和关系感在各模型上更一致；节奏（气泡、长短）；她不高兴时的反应。
- 可能变差：照抄样例、几句话反复用；不该撒娇时撒娇；样例里的事被当成真发生过（真实性）；每次请求多带约 3000 字。
- 应该不变：记忆、主动性、工具使用。

## 真实模型对比（2026-11-15）

测试副本、真实聊天循环加假的记忆工具、不启动 Peter。DeepSeek 官方、grok 和 Gemini（中转站）各跑 9 个虚构场景的「不带 / 带样例」，共 54 次，¥1.28，每格只跑一次，只能看方向。脚本：`experiments/voice-style-355/compare.py`；回复全文和盲看页只在 Lan 电脑。

| 项（不带 → 带） | DeepSeek | grok | Gemini |
| --- | --- | --- | --- |
| 9 条里用中文回的条数 | 3 → 0 | 1 → 0 | 4 → 0 |
| 平均气泡数 | 2.7 → 1.7 | 3.2 → 4.6 | 2.1 → 2.7 |
| 闲聊平均字数 | 172 → 193 | 71 → 194 | 147 → 171 |
| 认真长聊字数 | 929 → 530 | 1611 → 628 | 437 → 805 |
| 最长气泡平均字数 | 143 → 200 | 100 → 92 | 150 → 219 |
| 每条回复表情数 | 0 → 0.8 | 0 → 0.2 | 0.2 → 1.4 |
| 被指错时先查再答 | 否 → 否 | 是 → 是 | 是 → 否 |
| 说话人标签 | 0 → 0 | 0 → 0 | 0 → 0 |
| 每次请求输入 | 约 +850 token | 约 +850 | 约 +900 |

- 变好：语言和口气一致（带样例后 27 条全是英文、小写短句）；grok 会软、会用表情，闲聊不再只回一句；认真长聊 grok 和 DeepSeek 明显变短。
- 变差：①闲聊三个模型都更长；②DeepSeek 和 Gemini 把几行塞进同一条消息，气泡变少、单个气泡更长；③27 条里 2 条把样例当成真事提起，1 条在 Lan 说了和样例几乎相同的话时几乎照抄；④她烦的时候仍然追问（带不带都问）；⑤Gemini 被指错时没查就改口。
- 结论：机制可以合并（文件不放进人设目录就没有任何变化），但样例暂不对正式的 Peter 启用。等 Lan 盲看并决定：规则里加「她烦或受伤时不提问」、程序把一条消息里空行隔开的几段拆成气泡、再跑一轮的费用。

## 费用

每次请求多带约 3000 字（约 900 token），在可缓存的最前面。对比实验上限 ¥2。

## 验收步骤（Lan）

1. （样例启用后才做）更新并重开 Peter，把样例文件放到 `persona/peter.voice.md`（开发侧会代放并告诉她）。「上下文」页出现「他平时怎么说话」，能看到全文。
2. 同一个场景分别用 grok 和另一个模型聊几句：长短、气泡、语气像同一个人；没有照抄样例，也没有把样例里的事当真事提起。
3. 发一句真烦的话：他立刻收起玩笑，不追问。
4. 改一句样例点保存，下一句话就按新的来；点「关闭」，恢复原样。
