# 工单 013：简单前端（浅色网页聊天）

## 目标

lan 双击 `start-web.bat`，浏览器自动打开一个浅色、字大、对话气泡的聊天页，和 Peter 聊天；聊天、记忆、`/cost` 等命令、工具确认都和终端版一致。

## 当前状态

- 新增 `web_agent.py`（本机小服务，只监听 `127.0.0.1`，Python 标准库，无新依赖）、`web/index.html`（单文件，无外部请求）、`start-web.bat`（双击入口）。
- 聊天循环仍是 `veil_agent.run_chat`，没改；网页只提供它的输入、输出和确认函数。`veil_agent.py`、提示词、费用、记忆、工具文件均未改动，终端版 `start.bat` 行为不变。
- 页面：浅色默认，右上角可切深色（记在浏览器里）；顶部“花费”“记忆”按钮等于输入 `/cost`、`/memory`；其它斜杠命令直接在输入框打。`🔧` 工具行和 `📝` 记忆行显示成灰色小字。
- 需要终端输入 `y` 的确认（新建文件、追加授权）显示为“同意/拒绝”两个按钮，文字和终端一模一样。
- 安全：每次启动生成随机令牌，请求没有令牌、Host 不是本机、Origin 不是本机一律 403；不记录请求日志；一次只处理一条消息。
- 复用调查：Open WebUI、LobeChat 等成熟聊天界面都要自带后端或 Docker，无法显示我们的授权确认和记忆提示，且会绕开预算与权限；所以只写一个很薄的页面，聊天逻辑继续用现有代码。
- 只能开一个：终端版和网页版共用同一把聊天锁（防止两个窗口同时写聊天和记忆），开了网页就不能同时开终端版。

## 验收步骤（lan 在 Windows 上做）

1. 更新到最新 main 后，双击 `start-web.bat`：浏览器自动打开浅色聊天页；上面显示接上了几轮，之前的聊天内容能看到。
2. 用中文和英文各聊几句；点“花费”“记忆”能看到和终端一样的内容。
3. 让 Peter 新建一个测试文件：页面出现带完整路径的“同意/拒绝”。点拒绝没有文件，点同意才有。
4. 关掉命令行窗口后，页面顶部变红提示“和本机程序断开了”。
