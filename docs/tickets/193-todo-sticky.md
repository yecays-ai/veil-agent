# 工单 193：今日待办便签卡（每件事单独勾选）

## 背景
Lan 发现 Peter 把一天里的三件事写进同一条记录，圆圈只能勾整条。她想要一张便签纸：每件事一行，各有勾选框，勾掉划线保留（换配色与字体，不照搬黄色）。

## 改动
- 生活页「今日」「待办便签」顶部是一张便签卡：日期、星期、完成进度（如 1 / 3）、每件事一行自带勾选框，勾掉划线保留，每天重复的待办带 ↻，底部输入框回车即新增一条，可勾「每天重复」。配色与手写风字体跟随当前主题。
- `life_record` 工具说明改为：每件待办单独一条，不要把多件事塞进同一条记录。

## 验收（Lan）
1. 退出后双击 update.bat。
2. 打开生活页，在便签卡底部输入一件事回车，应多出一行，点方框打勾后划线。
3. 对 Peter 说“把今天要做的事记到待办里”，他应每件事一条。已有的那条三件事合并记录不会自动拆开，可让 Peter 重记。
