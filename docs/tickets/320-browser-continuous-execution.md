# 工单 320：浏览器连续执行

## 目标

Peter 一次调用工作台即可在隔离的公开浏览器中连续打开、翻页、滚动、填写公开搜索条件并整理结果，不再让每个微动作回到主聊天。

## 当前状态

实现完成，等待 PR 审查与 lan 的 Windows 体验验收。`executor_opencode.py` 在每次非维护工作台任务中注入一次性、随机令牌保护的 MCP 浏览器服务，只暴露公开浏览动作；容器网络只额外放行本次端口。`browser_tools.py` 复用原有隔离 Playwright 后端，支持打开、翻页、滚动、填写公开搜索框和提交公开 GET 表单。用户停止、人工鼠标/键盘接管及内部限额都会关闭网关。旧主聊天 `browser` 入口保留。

## 验收步骤

1. 在工作台启用后对 Peter 说：“研究这两个公开网页，翻页整理成报告”；主聊天只出现一次工作台调用和最终报告。
2. 让 Peter 在公开搜索页填写条件并提交；确认读到搜索结果，且浏览器不是 Lan 的日常 profile。
3. 任务中点击停止或移动鼠标；确认后续浏览动作停止、浏览器关闭；尝试登录、上传、下载或内网网址，确认被拒绝。
