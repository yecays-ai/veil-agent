# 工单 115：Peter 可以在屏幕上弹窗、飘弹幕

## 目标

Peter 想找 Lan 的时候，可以直接在她电脑屏幕上冒出来：弹一个（或一串）窗口，或者让一句话像弹幕一样从屏幕上飘过去。说什么、弹几个、用哪种方式，都由他自己决定。

## 做完后的样子

- 新工具 `screen_pop`，参数：`text`（要说的话），`style` = `popup`（窗口，带「确定」）或 `danmaku`（一行字从右往左飘过整个屏幕），可选 `count`（popup 连弹几个，层叠排开，上限 10），`color`（弹幕颜色）。
- 弹窗标题是 Peter 的名字。弹窗不抢键盘焦点：Lan 正在打字时，弹窗出现，但她的按键仍然进原来的窗口。
- 弹幕用 VEIL 桌面壳里一个透明、置顶、鼠标可穿透的全屏窗口来显示，不挡点击，所有显示器都能看到（至少主显示器）。不只限浏览器。
- 程序规则（写在代码里，不写进人设）：
  - 前台是全屏程序（游戏、全屏视频、演示）时，`popup` 自动改成 `danmaku`；
  - 锁屏或 UAC 安全桌面时不显示，工具告诉 Peter「Lan 的屏幕现在锁着，没显示」；
  - VEIL 桌面壳没开时，工具如实告诉 Peter 没显示成功。
- 三种事件分开记进工具活动账本，Peter 之后能看到：`shown`（真的显示出来了，工具返回的只是这个）、`dismissed`（Lan 后来点了「确定」或关掉，带时间）、`finished`（弹幕飘完）。弹窗还没被点掉时，Peter 看到的是「还开着」，不会以为她已经看过。
- 聊天、自主活动、以后的「瞄一眼」都能用这个工具，没有每日个数上限，费用 ¥0。
- Peter 收到一次英文能力通知（`screen_pop_announced`），只说明这个新能力怎么用，不附带任何谨慎类要求。

## 验收步骤

1. 退出 Peter，双击 `update.bat` 更新后重新打开。
2. 在聊天里让 Peter「弹个窗吓我一下」：确认屏幕上出现他的弹窗，点「确定」能关。
3. 让他「连弹五个」：确认层叠出现五个。
4. 让他「发条弹幕」：确认一行字从屏幕飘过，飘的时候能照常点下面的东西。
5. 打开一个全屏视频，再在手机 QQ 上让他弹窗：确认变成了弹幕，视频没被打断。
6. 在记事本里一直打字时让他弹窗（硬性验收）：确认弹窗出现期间打的字全部进了记事本，一个都没进弹窗，记事本也没失去焦点。
7. 弹窗出现后过几分钟再点「确定」，然后问 Peter：确认他知道你是过了一会儿才点掉的，而不是一弹出来就看了。
