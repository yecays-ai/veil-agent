# 工单 124｜瞄一眼和 Codex 监视能单独暂停

## 目标
活动页里「瞄一眼」和「Codex 监视」的开关能单独暂停和开启，不必暂停整个自主活动。

## 现状
桌面程序转发请求前核对白名单（`desktop/main.cjs` 的 `allowedChatRequest` 和弹出小窗的 `detachedAllowed`），白名单里没有 `/api/glance` 和 `/api/codex-watch`，请求被拦下，界面显示「设置保存失败」。本工单把这两个请求加入白名单。

## 验收
1. 退出 Peter，运行 update.bat，重新打开。
2. 在活动页单独点「暂停瞄一眼」：显示已暂停，自主活动仍是开启。
3. 单独点「暂停监视」：显示已暂停，之后 Codex 完成任务不再弹窗。
4. 在弹出的活动小窗里重复 2–3，结果相同。
5. 重启 Peter，两个开关仍是暂停状态。
