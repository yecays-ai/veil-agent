## 验收（lan 在 Windows 上做）
1. 打开生活记录：只有写过东西或贴过心情的日子有点，空白的日子没有点。
2. 点今天：每日待办能勾；点昨天：能看到昨天勾了哪几条，不能改。
3. 点日期只选中、不弹面板；点你的心情槽（空的也行）打开面板，切换分类，再从「更多 emoji」挑一个不常见的；在面板里再点它一次清除；关掉程序再打开，心情还在。
4. 新建一条带「几点」的日程，在列表里按时间排好。
5. 对他说「看看我这周日历上有什么」，他能说出你写的日程。
6. 让他把你写的一条日程改个时间：日历变了，详情里有修改历史，聊天里出一行灰色小字；让他删掉这条，他会说删不了。
7. 筛选「Lan」只显示你写的，筛选「Peter」只显示他写的。
8. 问他「后天有什么安排」，他知道。
