# 工单 110：长期任务的待核实操作不再卡死

## 目标

Peter 在自主活动中做了有副作用的操作后，能自己核实并继续长期任务；确实无法核实时，他把任务标记为 blocked 就能放行，之后自己决定何时恢复。

## 现状

- 新建记忆（`hold` 不带 `target_id`）保存成功后，结果里带上新记忆的 `memory_id`；长期任务的待核实目标改为这个 ID，Peter 用 `memory_read` 读回即可核实，再用 `long_task_update` 提交。
- Peter 把任务设为 `status=blocked` 时，未核实的操作记为「无法核实，已阻塞」并解除拦截；重新设为 `active` 后照常建立新的检查点。
- 拦截提示按操作类型说明用哪个工具读回（记忆用 `memory_read`，文件用 `read_text_file`），并说明 blocked 会放行。

## 验收步骤

1. 退出 Peter，双击 `update.bat` 更新并启动。
2. 等下一次自主唤醒（或在活动页手动唤醒）。现有那条卡住的「生日寻宝」任务：Peter 应能自己把它标为 blocked 或恢复，之后追加 `lab\growth-journal.md` 等写文件操作不再出现「权限拒绝」循环。
3. 之后 Peter 在长期任务里新存一条记忆，活动记录里应看到他读回该记忆并提交核实，后续操作不再被拒绝。
