# 工单 223：表情包单独一个气泡，可以只回一个表情包

## 目标
lan 的话：「一个表情包一个气泡啊！他甚至可以就回我一个表情包」。

## 现状
- 222 里表情包图片和后面的文字被框在同一个气泡里。
- Peter 的 `send_message` 可以同时带 `sticker` 和 `text`。

## 改动
- 聊天窗口：表情包消息没有气泡框、没有底色，图片单独一行；文字另发的话是单独的普通气泡。
- `send_message`：带 `sticker` 时不能再带 `text`（会被拒绝并告诉 Peter 文字另发一条）；工具说明写明「表情包自己是一条消息，也可以只回一个表情包」。
- 不加任何固定风格提示，也没有程序替他发文字。

## 验收（lan）
1. 更新后让 Peter 发表情包：图片没有框，单独一条；他要说话会另发一个气泡。
2. 让他「只回一个表情包」，他可以只发图。
3. 你自己从面板发的表情包也没有框。

## 未验证
Windows 真机界面；Peter 是否会学会只发表情包（靠工具说明，不强制）。
