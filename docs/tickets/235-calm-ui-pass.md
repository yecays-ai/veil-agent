# 工单 235：桌面界面去后台感（外框、头像、收起侧栏、说明文字、自适应）

## 目标

Peter 的桌面界面像一个整体的圆角窗口，而不是套在尖角矩形里的后台。

## 当前状态

窗口外有一层尖角外框，左上有 VEIL 品牌行，头像不能更换，收起侧栏时按钮与头像重叠，部分页面带解释小字和灰框卡片，宽度固定不随窗口变化。

## 验收步骤

1. 打开 Peter：最外面没有尖角长方形外框，整个窗口是一个圆角整体。
2. 左上角只有 Peter 的头像和名字，没有 VEIL 字样和 Logo；点头像可以选图片更换，换完所有 VEIL 窗口都变，重启后保持。
3. 点收起侧栏：头像在上、收起按钮在头像正下方、图标竖排，没有重叠。
4. 自主活动、MCP、设置页的外层卡片没有灰框，解释性小字已去掉，用细线分隔。
5. 拖动窗口宽度，或在 Windows 缩放 125%、150% 下：窗口宽于约 1100 时三栏，低于 1100 隐藏右栏，低于 860（例如独立拖出的页面窗口，或 200% 缩放）左栏收成图标，不出现横向滚动条、不挤成一团。
