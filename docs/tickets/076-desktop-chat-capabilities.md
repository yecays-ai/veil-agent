# 076 桌面聊天能力与旧网页壳清理

## 目标

桌面程序启动后显示 Peter 透明桌宠；聊天在本地独立深色窗口中运行，并沿用现有 VEIL Agent 聊天、审批、记忆、预算、自主活动及语音/图片 API。桌面入口不再打开浏览器网页聊天壳；浏览器用户仍使用原网页聊天。

## 当前状态

- 基于 main `a3eb961b1c1e8be85cd46661ea4e6745b0c66101` 建立 `ticket/076-desktop-chat-capabilities`。
- 桌面聊天页面使用本地 HTML/CSS/JS，集成原网页中已完成的图片、语音听写、按住录音、语音消息播放、连续聊天、能力记录、审批、自主活动和花费/记忆命令；Memory Dashboard 仅在 Agent 返回真实入口时显示。
- 桌面图片原图上限为 25 MB，自动缩放/压缩至 4.8 MB 以下，服从 Agent 现有 5 MB 媒体硬上限。
- 桌面启动脚本优先启动同级 E 盘桌面程序，否则启动本仓库构建版或开发版本。E 盘程序和源码目录已替换为本地聊天界面；Agent 数据和 `data\\desktop.json` 未改动。
- 桌面后端隔离测试 2 项通过；Electron 烟测通过本地聊天、历史、拒绝审批、图片上传、语音媒体接口、TTS 气泡、活动控件、收放、尺寸、沙箱和自定义菜单。烟测不启用真实麦克风、不连接真实 Agent 或付费服务。
- 已从 E 盘 `start-desktop.bat` 启动并核对进程使用 `E:\\Peter-Agent\\VEIL\\desktop-app\\VEIL Desktop\\VEIL.exe`。真实麦克风录音、在线转写、Peter 实际音色、图片问答及重启连续性仍待 Lan 验收。

## 验收步骤

1. 双击 E 盘 `start-desktop.bat`，确认透明 Peter 和旁边的紧凑深色聊天窗口；拖动/调尺寸并右键查看统一菜单，确认不再打开旧白色网页聊天。
2. 同一会话发送 3 条短消息、测试图片及中文语音，确认图片压缩后上传并留在历史、语音能转写并播放 Peter 回复；拒绝一次权限请求。
3. 重启桌面程序和 Agent，确认聊天历史、记忆、自主活动可继续使用；检查菜单中的收放、尺寸、活动和退出。
