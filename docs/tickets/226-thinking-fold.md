# 工单 226：思考和工具折叠显示

## 目标
Peter 每次回复前，聊天里只多一行灰色小字（例如「思考了 31 秒 ›」或「用了 3 个工具 ›」），点开才看到里面的内容；默认收起，工具调用不再一行一行占满屏幕。

## 里面放什么
1. 模型接口返回了思考文字的（DeepSeek、部分 Claude 接口等）：思考文字和工具调用按发生顺序排在一起。
2. 接口没返回思考文字的模型：只放工具调用，标题写「用了 N 个工具」。
3. 一次回复里的所有步骤归在同一个折叠块里；Peter 中途用 send_message 发出的消息仍是正常气泡，之后的步骤另起一个折叠块。
4. 标题的秒数是这次回复从开始到最后一步的耗时。

## 不变的地方
- 不多花钱：显示的是接口本来就返回的内容，没有多发任何请求；思考模式开关不动。
- 思考文字只显示，不写进聊天记录和记忆，也不增加发给模型的内容；单段最多显示 8000 字。
- 和现在的工具提示一样，折叠块只在窗口运行期间保留，重启 Peter 后不会恢复（真实聊天记录不变）。
- 「只看收藏」模式下折叠块隐藏。

## 验收
1. 更新并完全重开 Peter，随便让他用一个工具（例如搜一下东西），回复前出现一行灰字，默认收起。
2. 点开能看到工具行；模型有思考文字的会在里面按顺序出现。
3. 没有思考文字的模型，标题是「用了 N 个工具」，不是「思考了…」。
