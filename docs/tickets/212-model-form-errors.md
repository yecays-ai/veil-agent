# 工单 212：添加模型保存失败时，在表单里显示原因

## 目标
在「更多→模型」添加或编辑模型，点“保存模型”失败时，原因直接显示在表单下方；“最长输入”可以填任意整数（4096 到 2000000），不再被浏览器按 1024 一档卡住。

## 现状
Lan 11-04 反映：添加新模型点“保存模型”完全没有反应，点取消正常。模型个数没有 5 个的限制（上限 60 个，Lan 现有 3 个自添加 + 2 个内置）。读代码判断两个原因，真机未验证：① 保存失败的原因只写进聊天窗口，人在“更多”页看不到；② “最长输入”输入框限定 4096 起每 1024 一档，填 100000 这类数字，浏览器会静默拒绝提交。改动：失败原因显示在表单下方；该输入框改为每档 1。

## 验收
1. 更新并完全重开 Peter。「更多→模型」点“添加模型”，不填模型名直接保存，表单下方出现红字提示原因（不是没反应）。
2. 最长输入填 100000，其他项按真实信息填好，保存成功，模型出现在列表。
3. 保存失败时再点保存，不会卡住。
