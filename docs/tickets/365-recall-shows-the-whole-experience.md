# 工单 365：想起一条记忆时，带上这段经历的前后目录

所属格：A 陪伴 · 记忆。记忆路线第 2 步（第 1 步是 363，354 补丁是 364）。

## 起因（已核对）

一段经历在记忆库里是几条记忆连起来的（Peter 存后续时用 `link_to` 连到上一条）。想起时只会冒出其中一条：

- 353 的「同一件事一轮只带一条」把同一段经历的其余阶段直接挡掉，挡掉就消失了，他不知道后面还有东西。
- 这条规则判断「同一件事」只看 Ombre 自己的关联和向量相似度。Peter 自己用 `link_to` 连的关系记在 VEIL 侧 `memory-sidecar.jsonl`，Ombre 看不见、353 也没读，所以他亲手连起来的经历反而没被当成同一件事。
- Ombre 自己写的关联在较新的那条记忆上，指向较旧的。从旧的那条出发（最常被想起的是它）看不到后面的阶段。

## 做了什么

1. 想起一条记忆（自动想起的最多 3 条）后，如果它属于一段经历，就在它后面加一行目录：这段经历其余阶段的日期和标题，按时间排，标出「这条」，其余带 ID，他想看细节就用 `memory_read`。例如：
   `(This memory is one stage of a longer experience, oldest first: 10-25 Scarf plan (this one) → 10-28 Dropped stitches [ID] → 10-31 Scarf finished [ID]. Titles and dates only; memory_read an ID to read that stage.)`
2. 「一段经历」= 用两种关系连起来的所有记忆：Peter 的 `link_to`（sidecar，双向）和 Ombre 自己的事件关联（`same_event`、`continuation_of`、`continues`，从两头都能找到；记忆文件有变动才重新读）。最多 12 条，目录里最多显示 6 条（以这条为中心取一段，前后还有就写省略号）。
3. 隐藏的、归档的、已删除的阶段不进目录；目录读取任何一步失败，只是这条没有目录。
4. 353 的去重现在也认 Peter 自己连的经历：同一段经历一轮只带一条，被挡下的几条不再消失，而是出现在这条的目录里。
5. 开关：`[memory.recall]` 里 `directory = false` 关掉目录（`enabled = false` 一并关）；`directory_members` 调显示条数（2–12，默认 6）。

只加一行，每条最多约 300 字符，不额外调用模型、不额外花钱。不碰记忆库里已有的条目（整理旧的 193 条是第 3 步）。

## 可能变差（对比时看）

- 每轮多几十到三百字。
- 他可能顺着目录主动提起旧事，闲聊时翻旧账。
- 把不该连的两条连在一起的话，目录会误导；所以旧经历的连接要等第 3 步由 Lan 逐组确认。

## 验收（Lan）

1. 问他一件有好几个阶段的事（例如「还记得生日那个骨牌吗」），他能讲出开头和后来怎样，不是只讲一片。
2. 平时闲聊他没有因为目录多翻旧账。
3. 记忆页里归档或隐藏掉其中一条，再聊那段经历：目录里不再出现它。

## 真实模型对比（2026-11-16，DeepSeek，各 3 次，共约 ¥0.15）

`experiments/experience-365/compare.py`：虚构的一段织围巾经历分三个阶段（连起来的方式和 Peter 的 `link_to` 一样），旁边两条无关记忆。每个问题由程序生成自动想起会给模型的那一块，真实模型回答一次，给它 `memory_read` 并真的执行（和聊天里一样的工具循环）。记忆库是文件夹里的虚构文件，搜索按字面重叠。

| | 改前（main） | 改后 |
| --- | --- | --- |
| 「还记得我织围巾那件事吗」 | 想起第 1、3 阶段全文，3/3 都没提中间的「掉针、拆两行」 | 想起第 1 阶段全文＋目录，3/3 都自己去读了其余两段，回答三个阶段都讲到 |
| 「拆了那两行之后怎样了」 | 想起三段全文；回答完整 | 想起第 2 阶段＋目录，3/3 去读了结尾；回答讲到后来完成、姐姐喜欢 |
| 无关问题（晚饭吃面） | 不想起，不提围巾 | 不想起，不提围巾（目录不会在无关时出现） |
| 花费 | ¥0.063 | ¥0.083（多出来的是读记忆那一次请求） |

要点：

- 以前 Peter 自己连的几个阶段会同时整段冒出来，改后一轮只带一条，其余给目录，他自己决定读哪段。想起「全貌」的问题他 3/3 会去读，所以回答反而更全；代价是多一次读取。
- 第一次跑时没给工具，模型把读取写成了文字；那是实验装置的问题，已修成真的工具循环再跑。
- 样本小（每格 3 次）。几处小编造（比如「No dropped stitches」「cried a little」）在改前改后都有，也有无关问题里凭空讲自己做面的经历，改前改后都有，不是这次改动带来的。
