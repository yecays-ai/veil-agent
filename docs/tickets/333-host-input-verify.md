# 工单 333：Peter 汇报桌面输入结果必须有依据

真机第三轮：Peter 汇报"已输入 hello"，记事本却是空的（第二次 Type 带坐标 [1018,872]，该点不在记事本窗口内，工具没报错，模型据此宣称成功）。

## 目标（代码强制）
1. Type 带坐标时，VEIL 先取前台窗口矩形（GetWindowRect）；坐标不在前台窗口内就拒绝，并告诉 Peter 先切到目标窗口、重新 Snapshot。
2. Type 完成后由网关自动读回：先读前台窗口焦点控件的文本（WM_GETTEXT）；没有这段文字就把结果改成"输入未生效"（错误）。读不到控件（浏览器、新式控件）时用 Snapshot 文本核对；仍看不到则返回"未确认，需截图核实再说成功"；按了回车的输入无法核对，同样要求 Peter 核实。
3. 任务说明（HOST_NOTE，提示词建议，非代码强制）：Type 前先切窗口并 Snapshot；输入后以 VEIL 的读回结果为准；拿到够用的信息就先写文件再继续核实。单次 ¥0.5 上限不动。

## 已知限制
- 用 label 而非 loc 的 Type：坐标由 Windows-MCP 内部解析，VEIL 在点击前无法校验窗口范围，只靠读回兜底。

## 验收（Lan 电脑测试副本，host_mode 开）
场景：打开记事本输入 hello 不保存。Peter 要么真的输进去且读回确认，要么如实说失败。
