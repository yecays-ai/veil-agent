# 077 桌面端退出、更新与浅色主题

## 目标

从桌面菜单可以完全退出桌面端和后台 Agent；Main Update 更新并重打包原有那一份桌面程序；聊天窗口提供可记忆的浅色/深色切换。

## 当前状态

实现位于 PR #120：菜单退出会在 Agent 不可达或请求超时时仍关闭桌面端；更新脚本更新 main 后重打包已有桌面目录；聊天标题栏提供主题切换。Windows updater 回归测试已补齐模拟打包依赖的夹具，并在项目虚拟环境中通过。CUBIC 复查请求因试用审查额度耗尽而未启动；最新 PR 检查尚待代码更新后重跑。

## 验收步骤

1. 用桌面菜单选择“完全退出（含后台 Agent）”，确认窗口和桌面形象都关闭。
2. 运行原来的 Main Update 和 Start Desktop，确认更新后仍从原有位置启动同一份软件。
3. 在聊天标题栏切换浅色/深色，关闭并重开聊天，确认所选主题保留。
