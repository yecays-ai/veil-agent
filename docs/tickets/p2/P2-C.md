# P2-C · 标签/分类治理与历史记忆核实

## 1. 当前确认的目标

取消无意义的自由标签膨胀，保留真正有用的结构化信息；完成历史清理与 145 条旧记忆核实。
标签方案由开发方基于实际功能、数据和成熟方案提出，不要求 Lan 凭空设计技术分类。

- 先审计再决定：`tags`/`domain` 谁生成、谁修改；聊天召回、BM25/向量、判官、联想、事件归组、
  关系、管理页是否依赖；自由标签是否带来额外模型调用/存储冗余/错误分类。
- 目标默认（按审计结果可调整）：
  - 停止新增自由文本标签；`tags` 字段保留为只读历史/审计数据，不再进入 UI 筛选与检索。
  - 不预设必须保留固定分类。只有管理页筛选被证明有用时，保留一个受控分类字段；
    提议 7 类：`relationship`（人物/关系）、`experience`（共同经历）、`preference`（喜好/习惯）、
    `commitment`（承诺/约定）、`work`（技术建设）、`emotion`（情绪/冲突/修复）、`daily`（日常），
    另加 `unclassified`。每类必须有明确边界，不能为每条记忆发明新类；无法归类保持 unclassified。
  - 来源、时间、重要度、状态、锁定、版本、事件、记忆间关联保持结构化，不混进标签。
  - 若审计证明分类无实际收益，则连固定分类也不保留，只保留结构化字段与语义检索。
- 历史处理：统计标签/domain 数量、重复率、一次性比例、功能依赖；对无用自由标签做可恢复清理；
  有依据的旧分类迁移；无法准确映射保留 unclassified；不得改正文/来源/事件关系/版本/原始 ID；
  保留迁移前备份与可核对报告；验证旧/新记忆仍能正常检索。
- 145 条旧记忆：先核实实际剩余、与 69 篇事件的关系、哪些已被覆盖；输出逐条清单；**禁止盲目
  重新归组**；只对证据充分且 Lan 同意的项做迁移。
- 本单完成前不得把标签清理留给记忆页面。

## 2. 代码与数据现状

- 284 条记忆：2897 次标签使用、2107 个不同标签、1809 个只出现一次；domain 82 类。
- Brain 检索（`brain_retrieval.py`）只用标题+正文的向量/BM25，不读 tags/domain；记忆页
  `panel_entries` 与 Ombre 搜索/页面仍可能依赖；Ombre 回退期间需核对。
- 标签写入：`memory_native._hold` 把 Ombre 返回的 domain/tags 写入页面元数据；`brain_sync`
  只同步字段，不生成标签。停止新增应在写入入口/工具参数层处理，不靠事后清理。
- 145 条归组仍是 HANDOFF 未做项（HANDOFF 135/209 行），与 69 篇事件迁移可能部分重叠，需核实。
- 事件/故事数据由 P2-A 入库；本单读取事件以做归组证据，不改事件正文。
- 页面契约：P2-B 保持 API 兼容；本单如改变筛选/统计字段，必须同 PR 更新契约与测试，页面改版仍
  留给后续页面工单。

## 3. 用户体验验收步骤（隔离）

1. **依赖审计报告**：列出 tags/domain 的生成、保存、修改、读取点；哪些是检索/判官/联想/事件/
   页面实际依赖；哪些是纯展示/冗余；给出保留/弃用结论和数据依据。
2. **分类方案验证**：按提议的 7 类 + unclassified 做隔离映射试验；统计覆盖率、冲突率、未分类率；
   对比“有分类筛选”和“无语义标签”的页面/检索体验；若分类无收益，记录并采用“不保留固定分类”方案。
3. **历史清理**：隔离副本上清理无用自由标签；无依据的不强映射；正文/来源/事件/版本/ID 完全不变；
   迁移报告列出处理/保留/未分类数量；迁移前备份可恢复。
4. **检索回归**：清理前后用固定问题集对比旧/新记忆召回、事件召回、不同措辞；不得出现重要遗漏增加；
   Ombre 回退读取（P2-B 的独立实例）也不能因清理失效。
5. **新记忆行为**：新建/修改记忆不再产生自由标签；分类为空时保持 unclassified，不强行填满；
   管理页筛选/统计使用真实字段，不再出现成千上万标签。
6. **145 条核实**：输出剩余清单、与 69 篇事件的覆盖关系、建议处置（保留/合并到事件/新建事件/
   不动）；不执行无证据归组；Lan 确认后才迁移，迁移有备份、报告、可回退。
7. **页面契约**：筛选/统计 API 字段与统计口径测试；页面后续可直接使用，不得把治理留给页面。

通过标准：新自由标签写入 0；历史无用标签清理完成且正文/事件/版本/ID 不变；分类（若保留）≤7+未分类；
检索无重要遗漏增加；145 条有逐条清单和处置结论；报告与备份齐全。

## 4. 交付前自审（本单强制）

- 历史自由标签可以临时保留供迁移/审计，但**最终交付必须完成无用标签的实际清理**，不能只隐藏 UI。
- 分类是否保留由实际页面筛选价值、分类冲突与误分类决定；七类方案是待验证候选，不是定稿。
- PR 说明和 STATUS/HANDOFF 写明每条“完成/未完成 + 证据”、清理数量、备份与回退方式。
- 审查评论只改功能/数据/安全问题；一次性修改、一次性推送。
