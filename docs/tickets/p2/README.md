# VEIL Brain P2 三单（A/B/C）

- 全部通过才算 P2 完成；之后才是 P3 下线 Ombre，再开发记忆管理页面。
- 顺序：P2-A → P2-B；P2-C 可在 A 之后与 B 并行，但必须在页面之前完成。
- 开发、模型调用、聊天、故障注入、迁移演练全部在隔离副本/独立进程/独立端口进行；
  不得启动、停止、修改正式 Peter，不得向正式聊天发送测试消息。
- 每单独立分支/PR；PR 更新 STATUS.md、HANDOFF.md，并附实际验收证据。
- 未完成隔离验收不得报告完成，不得自行执行正式切换。

## 每单交付前自审（必须）

1. 推 PR 前逐条对照本单工单：覆盖、边界、验收步骤、数据安全、回退要求是否全部完成；
   未完成项不得用“后续单”掩盖。
2. 自审结果写进 PR 说明与 STATUS/HANDOFF，包含“逐条打勾/未打勾 + 证据链接/命令输出”。
3. Cubic/审查评论只处理影响功能、数据、安全的问题；格式/风格直接忽略。实质问题**一次性合并修改、
   一次性推送**，不反复触发 CI。
4. 每单完成后在早间报告里单列：自审结论、未处理项、是否可进入下一单。
