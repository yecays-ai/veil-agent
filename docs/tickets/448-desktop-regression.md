# 448 · 保留桌面高频入口并提供只读模型配置总览

- 产品线：A（陪伴核心）与 B（电脑干活）的桌面管理入口；不扩大能力或权限。
- Lan 能看到五种模型用途的配置选择、证据来源和是否待重启，不需要翻配置文件。无法证明的运行值明确标注。
- 验收：在隔离 Windows 桌面打开设置，点「读取配置总览」，检查正常、缺凭据和待重启；切回聊天点「＋」，再到生活记录选日期、看或改一条演示待办。

## 目标

先立只读注册与投影契约，后续再逐域接入；保留现有聊天菜单和日历的真实行为。

## 当前状态

复用原模型设置的解析器和运行证据、Electron 请求守卫、现有设置页。不引入依赖、不重写编辑表单。不把模型配置选项当已运行；没有消费端证据时显示无法核实。凭据仅显示存在性，不探测供应商。现有聊天「＋」五个入口与生活记录月历增加离线行为回归。

## 影响与接入

| 场景 | 变化 | 验证 |
|---|---|---|
| 主窗口及独立设置窗口 | 新增只读 GET，不接受角色替换参数；沿用请求守卫 | 路由和拒绝路径测试，Windows 真机待验 |
| 聊天及生活记录 | 不改发送、日历或保存逻辑 | 离线行为回归、后续桌面换壳同测 |
| 停止、费用、权限、存储 | 不启动任务、不调用模型、不改配置权限或数据；仅沿用本机鉴权 | 测试用假模型目录与内存 DOM |
| 升级与回退 | 无迁移，移除入口和读接口即可回到原设置页 | 保留旧表单和保存入口 |
