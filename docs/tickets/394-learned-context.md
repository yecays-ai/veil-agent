# 394 Peter 页与已学习的上下文

属于 A（陪伴核心）。Lan 不用开文件夹就能改 Peter 的人设、背景、关于她的笔记和 Lan 自己的人设；更重要的是，Peter 吵完架学到的**关系成长**和**现在还没过去的事（ongoing）**会每次带着，而不是埋在 2,740 字节的事实堆里。

## 目标

- 新建「Peter」页：个性、背景资料、他记的你（Learned Context）、关于你（Lan 的人设）。
- Learned Context 三块：ongoing（条目）、关系成长、重要事实；共享 4,000 字节预算，不设死板分块上限。
- ongoing 由 Peter 自主维护：创建/更新/完成/归档/重开；更新前追溯聊天与记忆；保留来源；证据不足标「尚不确定」。
- 关系成长由 Peter 写，Lan 能看能改；不强制每次冲突记录，不新增模型总结调用。
- Lan 的修改覆盖 Peter 的；用户输入优先。
- 旧 `about-lan.md` 2,740 字节完整迁入「重要事实」，不压缩、不删除、不静默截断。
- 三块是背景资料，不要求每轮提及；不新建第二套记忆系统。

## 当前状态

- `about-lan.md`：2,740 字节、约 34 段、单块；每次请求都带；界面看不到。
- `profile_notes.py` 只有单文本 `profile_append/profile_replace`；上限 3,000。
- persona 是启动时读入的，改文件不会下一句生效。
- 没有 Peter 页；背景、人设、Lan 人设都没有界面。
- 错误没有统一的页面日志；超限、损坏都只返回一句。

## 验收步骤

1. 打开「Peter」页：看到个性、背景资料、Learned Context 三块、关于你；每块显示字符/字节/估算 token 和上次保存时间。
2. 旧笔记完整出现在「重要事实」；迁移前后内容逐字节一致；备份和旧文件都在。
3. 改人设一句话保存，下一条回复就按新的说，不用重启。
4. 改「关于你」一句，Peter 下一轮不再按旧的说；他之后再改，页面显示「他后来改过」。
5. 在 ongoing 新建一条「Lan 生气没回」，下一次自主醒来在提示里能看到（位置在历史后、用户消息前）；完成后不再出现。
6. 超 4,000 字节保存被拒绝，提示超出多少字节、哪一块；已有内容不动。
7. 文件损坏时页面指出文件/字段/行和日志路径，聊天继续用旧笔记，不假装正常。
8. 有未保存改动离开页面，弹保存/不保存/取消；取消留在页面。
9. 三块只作为背景，不出现每轮主动复述。

## 不做

- 不改召回、判官、记忆库；不做收藏权重、少想起、自动总结关系成长。
- 不按最后一条消息/关键词/情绪自动触发 ongoing。
- 不静默截断、不为了迁移删旧内容。
