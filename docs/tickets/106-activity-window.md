# 工单 106：独立活动监视窗口与实时工具记录

## 目标

Lan 可以像浏览器一样把主窗口里的聊天、活动、记忆、更多任一标签拖成可移动、缩放的独立 Windows 窗口并合并回来；活动窗口实时显示 Peter 在聊天、自主活动和长期任务中的真实工具开始、结果与历史。

## 当前状态

基于 `main` `566280d` 开发。现有 Electron 只有主聊天 `BrowserWindow`，活动页只展示自主活动摘要；`data/<角色>/tools.jsonl` 原先只在调用结束后写终态，没有调用 ID，也没有通过 `/api/events` 提供统一时间线。现已让工具开始与结束使用同一 `call_id` 追加到原账本，由后端折叠成单条实时记录；四种独立窗口继续加载同一份 `chat.html?view=<页面>`，复用现有轮询、主题、透明度和 `desktop.json` 窗口设置，可同时拆出并各自恢复位置尺寸，不改变 Agent 能力、权限、预算、聊天、记忆或 Lab 数据。常见凭据格式在写入详情前隐藏，各独立页面只开放自身原有操作需要的 IPC/API。

复用检查：Electron 官方 `BrowserWindow` 提供 Windows 窗口移动、缩放、位置事件和 bounds；原生标签合并 API仅适用于 macOS。查阅的 `electron-draggable`（MIT）与 `electron-drag` 只解决无边框窗口拖动，不提供跨窗口标签拆合，且后者带原生模块。因此本单只借鉴拖动边界判断，直接复用项目既有 Electron 主进程、同一 renderer 和设置存储，不新增依赖；拖回采用稳定的「合并回主窗口」按钮。

## 验收步骤

1. 打开桌面主窗口，分别把聊天、活动、记忆、更多标签拖出；确认四个标签都能成为可移动、缩放的独立 Windows 窗口，并可分别用「合并回主窗口」归位。
2. 让 Peter 连续读取/写入 Lab、调用 `hold` 或 `breath_search`，再触发一次自主活动；确认独立窗口即时出现“进行中”，随后同一条更新为成功、失败或权限拒绝，可展开查看时间、对象、来源与结果，并能按五类筛选。
3. 同时保留两个以上独立页面并重启 VEIL；确认各自的拆分模式、位置、尺寸、日夜主题和透明度保留，活动历史仍在，聊天、语音、图片与 Peter 的工作不中断。
