# 工单 095：桌面消息操作与 Lucide 图标

## 目标

Lan 可以在 VEIL Desktop 中按旧版小手机的消息菜单直接复制、删除、撤回或重新生成，并在重启后看到一致的聊天记录。

## 当前状态

旧版 `components/chat/message-actions/` 使用 Lucide 菜单、贴近气泡的边界定位、删除确认和操作反馈；`lib/chat/recall.ts` 将撤回限定为本人两分钟内的已发送消息，`lib/chat/turns.ts` 按完整 Peter 回复轮判断重生成。旧版仓库没有可确认的复用许可证，因此本工单复用行为与布局约定，不复制其组件代码。桌面端现有消息来自 Agent `chat.jsonl` 事件账本，媒体由 `data/<角色>/media/index.jsonl` 管理；开发分支从最新 `main` `94bdc35` 建立。

## 验收步骤

1. 在 Peter 与用户的文字、图片、语音消息上右键，对照旧版检查菜单、图标、悬停、确认反馈和窗口边界。
2. 复制、删除、撤回用户消息并重新生成 Peter 多气泡回复；重启后核对记录和后续上下文。
3. 切换日间、夜间和半透明背景，检查菜单及发送、附件、语音、导航、窗口按钮图标。

## 实施与待验收

- 桌面消息菜单、持久化删除/撤回、按整轮重新生成、媒体引用清理及本地 Lucide 图标已接入现有 Agent 聊天账本和 API。
- 普通文字消息提供八格菜单，角色不适用操作会禁用；语音菜单提供转写、收藏、下载、删除及用户撤回。
- 用户只能撤回自己两分钟内、且尚无 Peter 回复的消息。Peter 的撤回是他自己的决定：普通回复和自主活动均可调用 Agent 内部撤回工具，只有成功保存当前回复后才把本人消息持久化为撤回标记；用户菜单不能撤回 Peter 的消息。
- 新 Peter 回复记录本轮自动注入的 Ombre 记忆引用，Memory 菜单读取对应原文；无引用的旧行显示无可读取引用。删除聊天记录不级联删除无独立来源关联的 Ombre 长期记忆。
- 删除/撤回重建内存聊天历史并实时通知 UI；媒体仅在聊天账本中无剩余引用时清理。
- Python/JavaScript 语法检查与 `git diff --check` 通过；未运行自动化测试，也未使用真实聊天数据。
- 右键菜单截图已用合成消息生成，供用户确认；截图确认前不推送、不建 PR。
- Electron 打包运行、重启后记录、图片/语音操作以及日夜/半透明主题均待真实 Windows 验收。
