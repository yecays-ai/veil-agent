# 工单 416：重复工具结果与无进展循环保护

- 格：A 陪伴核心（工具循环是聊天能力）
- 做完 lan 能多做的一件事：Peter 重复读同一个文件/列表时，不再把相同结果整段塞回上下文；连续两批没有新信息时会收到一次收束提示，不再无限重复。
- 验收：让他连续读同一个文件两次，第二次工具结果应显示「结果相同」而不是再贴一遍全文；普通聊天不应变慢或强制单气泡；自主活动的步骤/预算上限保持原样。

## 目标

在同一轮工具循环里识别完全相同的工具结果和重复失败，压缩重复内容，并在连续两批没有新信息时注入一次收束提示；不关闭工具、不删除结果、不改变权限/记忆/多气泡。

## 当前状态

- 旧行为：同一个文件读两次会把全文再追加一次；连续无新信息时只能等 max_steps 或预算耗尽。
- 本 PR：
  - 每次工具仍真实执行，拿到最新结果后再比较；只有完全相同的只读结果才压缩成一句「Same result as step N; no new information」，不会用旧缓存冒充新结果。
  - 动态工具和有副作用工具不做压缩（peek_screen、web_fetch、write_file 等）；测试覆盖动态结果和写操作仍返回完整内容。
  - 相同参数重复失败时压缩成「Same failure as step N; change the arguments or stop」，不重复贴长错误。
  - 连续两批没有新信息（全重复/全失败/空结果）时，普通聊天注入一次收束提示，最多两次；自主活动不加提示，沿用现有 step/预算上限。
- 未做：P2-1 首气泡提示、P2-2 工具调用文字 trace，仍按「不强行完成全部候选项」延后。

## 验收步骤

1. 让 Peter 连续读同一个文件两次，看第二次工具结果是否只显示「结果相同」，不再重复全文。
2. 普通聊天发一句普通话，确认没有多出强制气泡或变慢。
3. 自主活动跑一次，确认步骤/预算上限与之前一致。
