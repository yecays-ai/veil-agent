# 379 重新生成时不丢想起的记忆

所属格：A（记忆与人格连续性）。

## 现状（真机证据，2026-11-17）
13:18 Lan 问「11 月 13 号你又说了我禁的那句话，后来怎么样？」，自动想起带出 3 条相关记忆，Peter 答了。13:23 她按「重新生成」，这次自动想起是空的（memory_ids=[]），Peter 只能自己搜聊天记录，搜歪了，答错。

根因：自动想起的冷却（工单 353）一带出就记账，3 轮内不再带；重新生成是同一句话再想起一遍，正好落在冷却里，三条全被丢，且冷却是「丢了不补位」。同类路径：出错、停下、没发出任何回复的一轮，以及因输入上限被裁掉的记忆，也白白记一笔冷却。

## 改动
1. 重新生成：被替换那一轮带出过的记忆（回复行里的 `memory_refs`）先从冷却里放出来，再正常想起。
2. 一轮没发出任何回复（出错、停下、空）：撤销这一轮的冷却记账，恢复到这一轮之前。
3. 被输入上限裁掉、没真正给到模型的记忆：不记冷却。
不改冷却规则本身、不改记忆内容、不改 `[memory.recall]` 配置。

## 验收
让 Peter 想起一条旧事（问「还记得……吗」类以外的普通问法，使它走冷却），按「重新生成」：Recall Memory 里仍有同样的记忆，回答仍有依据；正常连续聊天里同一条仍不会 3 轮内反复冒。
