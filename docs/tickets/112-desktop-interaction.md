# 工单 112：Windows 桌面交互能力

## 目标

Lan 可以让 Peter 打开白名单应用、切换指定窗口，并通过 UI Automation 操作控件和输入文字，且每步都能核验结果并优先让人工接管。

## 当前状态

工单 111 已通过 PR #157 合并为 `b64875d`，提供后台窗口观察、敏感界面拦截及与 QQ 共用的桌面互斥锁；Lan 的 Windows 实机验收仍待进行。Peter 已有 `uiautomation==2.0.29`，本工单沿用该依赖和工具循环、权限审批、活动账本及自主活动暂停机制。已阅读 Microsoft winapp CLI 固定提交 [`6564e7a`](https://github.com/microsoft/winappCli/tree/6564e7adba6d339f2b06868baca050e54687a2b3) 的 UI Automation、精确目标解析及交互协调实现；采用其 UIA 优先、显式 pattern、精确窗口身份和动作前重查的做法，不复制代码、不增加框架或依赖。初始程序白名单只开放记事本。截图仍用于观察；由于尚无可证明坐标与窗口布局绑定的点击校验，本工单不开放视觉坐标点击。

## 验收步骤

1. 让 Peter 打开记事本并输入中英文混合文字；确认文字出现在记事本、内容准确且没有自动保存。
2. 同时打开几个窗口，让 Peter 切换指定窗口，再通过 UIA 打开普通菜单；核对窗口没有选错、菜单状态确实变化，并检查需要审批的动作先由 VEIL 询问。
3. Peter 操作时用鼠标或键盘接管，确认他停止后续桌面动作；在活动窗口查看开始、结果或中断记录，并确认未授权应用启动及删除等动作被拒绝。
