# 工单 401：指令页可读性、去重与编辑

## 目标

工单 400 的「指令」页 Lan 打开后不能用：展开的内容被卡片高度裁掉，看不见；同一份人设/背景/样例在 Peter 页和这里各出现一次，改哪份都不知道。

本单修三件事：

1. 展开后完整显示原文，页面自己滚动，不再被 130px 的 pre 高度裁掉。
2. 去掉重复：人设、背景、说话样例、他记的你、你的设置只在原页面（Peter 页 / 上下文页）改，指令页不再列。
3. 可在页内编辑：每条「文本」指令展开后有「改这一条」，保存即写覆盖文件，下一次请求（自主活动：下一次醒来）生效；带搜索。

## 醒来记录格式已分开

原先把「行为段」和程序读活动记录用的四行（Decision / Reason / Focus / Next step）放在同一个可编辑文件里，
删掉四行会让这次活动记不下来。现在拆成两条：

- `autonomy.wake.rules`：行为段，可改。
- `autonomy.wake.protocol`：四行格式，只读，由程序接在行为段后面；页面显示原因。

拼出来的醒来提示与拆分前逐字节一致（对比过）。

## 交互

- 分类标题 + 条数 + 可改条数；每条一行，点开看用途、触发条件、来源、原文。
- 搜索：按名称、触发条件、原文过滤，命中处显示一行摘要；命中文本的条目自动展开。
- 编辑：textarea 全宽、保存/取消、失败原因就地显示；保存成功提示「下一次请求 / 下一次自主活动用新内容」。
- 「每轮生成」的条目只展示说明，没有原文也没有编辑框。

## 不碰

- 不改请求组装、不改缓存顺序、不改权限与预算。
- 不做版本历史、对比、恢复默认（Lan 2026-11-20 明确不要）。

## 验收

1. 打开「指令」，展开「醒来提示的行为段」能看到完整原文，能滚动。
2. 点「改这一条」，删掉一句保存；下一句聊天仍正常（这一段主要影响自主活动）。
3. 打开搜索输入「记住」，只剩相关几条；清空恢复全部。
4. 人设、背景、样例、他记的你在指令页找不到（去 Peter 页 / 上下文页）。
