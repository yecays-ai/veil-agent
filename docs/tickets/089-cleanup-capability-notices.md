# 工单 089：合并能力通知重复代码与新对话遗留字段

## 目标

能力通知（自主活动、长期任务、照片、语音输入、语音输出）只走一个公用写入函数，以后新增能力时不用再复制一份；“新对话”游标文件不再写已退役的 language 字段。Peter 收到的通知文字、发送时机、`capabilities.json` 格式和新对话行为都不变。

## 当前状态

`tools_agent.py` 的五个 `announce_*` 改为调用 `_announce_once`，各自只保留通知文字和原有出错处理（自主活动/长期任务出错时停用工具并报错；照片/语音出错时返回 False）。`chat-session.json` 只写 `start`；旧文件里的 `language` 字段照常可读。不新增依赖，不改用户数据。

## 验收步骤

1. 更新并启动 VEIL，发一条普通消息，Peter 正常回复。
2. 在桌面版点“新对话”，确认旧聊天不再出现在对话里，Peter 正常回复；重启后仍是新对话。
