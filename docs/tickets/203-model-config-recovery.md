# 工单 203：模型配置安全恢复与原子保存

## 目标

模型配置损坏时 Peter 明确停止付费请求；模型与 API Key 保存中断后重启恢复到一致状态；提交前回滚旧配置，提交后保留新配置。

## 当前状态

`model_settings.py` 原先把已存在但损坏的 `models.json` 当空配置，并在选中模型无效时回退。保存时先改 `.env`，再改 `models.json`。本工单在现有配置类中严格读取已存在的文件，并用同目录临时文件、替换与事务记录恢复两份文件。参考 [python-atomicwrites](https://github.com/untitaker/python-atomicwrites) 的同目录替换和刷盘思路；它已经归档且只保证单文件，故没有增加依赖。真实 Windows 桌面体验尚待验收。

## 验收步骤

1. 更新桌面版后正常切换到虚构测试模型，保存并重新打开 Peter；检查模型与 Key 状态保持，下一次测试请求使用新模型。
2. 在隔离副本中损坏 `models.json` 后启动，应看到配置错误而非另一模型；原文件仍在。修复文件并重启 Peter 后可继续聊天。
3. 在隔离副本中模拟磁盘写入失败；页面提示保存结果未确认，旧配置保持一致，解除故障后可重试保存。
4. 在隔离副本中强制中断保存，再重启；启动时恢复一致的模型与 Key，随后可正常保存。正式 `.env` 不用于故障注入。
