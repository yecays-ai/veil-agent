# 工单 005：自己记、自己想起（第一部分）

对应重建计划阶段一 · 大块 3。大块 3 拆成两张工单。本工单做“不用说‘记住’也会记，重启后自己想起”；Peter 主动调用记忆工具（自己决定记、自己去查）要等有工具调用之后，放到下一张。

## 目标

lan 随口聊天，不说“记住”。Peter 自己把值得留下的事记进长期记忆，每记一条屏幕上显示一行。关掉再开，聊到相关的事，他自己提起来。

## 复用

- 长期记忆用 [Ombre-Brain](https://github.com/P0luz/Ombre-Brain)（MIT），整个接入，不复制它的代码。已核对提交 `115d831`：
  - 支持 stdio 传输（`src/server.py` 的 `transport`）；
  - 记忆桶目录可配（`config.example.yaml` 的 `buckets_dir`），存成 Markdown；
  - 工具 `breath()` 不带参数时返回最重要的记忆；
  - `breath_search(query, mode="automatic", with_ids=True)` 用于每轮自动召回，会尊重 dont_surface/digested 标记；
  - `hold(content, feel, quotes, source_content, ...)` 写入一条，正文逐字保存。
- 客户端用官方 `mcp` Python SDK 连 Ombre，不自己写协议。
- 实现前先确认 Ombre 在 Windows + Python 3.11/3.12 上能装能跑。装不上或要改它的代码，先停下在 PR 里说明，不要硬改。

## 范围

1. **每个角色一个记忆库**：Peter 的记忆放在 `data/<角色 id>/memory/`（`data/` 已在 `.gitignore`）。整个聊天期间只开一个 Ombre 进程，退出时关掉。程序不让一个角色读另一个角色的目录。
2. **不偷偷花钱**：Ombre 自己也能调模型（打标签、压缩、向量）。本工单把这些全部关掉，不给它配 key；它会用本地默认值保存。所有要花钱的请求都走我们自己的预算账本。
3. **中文能搜到（重点）**：没有向量，检索只靠 Ombre 的 BM25 关键词（jieba 分词）。旧 VEIL 就栽在“关键词搜不到”上。lan 中文英文都会说，Peter 说英文，只存一种语言的话，用另一种语言提起就搜不到。所以：
   - 确认 `jieba` 和 `rank-bm25` 装上了（它们在 Ombre 里是软依赖，缺了不报错、检索静默失效）。启动时检查，缺了就提示一行。
   - 记忆正文中英双语：先一段中文，再一段英文，说的是同一件事。原话照原文放 `quotes`，不翻译。
   - 每条记忆末尾加一行检索词：中文关键词 + 英文关键词 + lan 以后可能换的说法（比如“面试 / 求职 / 找工作 / interview”）。由补记请求一起生成，不多花请求。
   - 测试里放一组真实感的例子：用中文提起英文聊过的事、用英文提起中文聊过的事、换个说法提起，都要能召回。召回率写进 PR。不达标就停下在 PR 里说明，由 lan 决定要不要加一个便宜的向量服务（计入预算）。
4. **后台补记**：每满 4 轮，用一次请求（同一个角色模型，计入预算，开 JSON 输出）读这 4 轮原文，挑出值得长期留下的事。
   - 每条要带一句 lan 或 Peter 的原话。程序检查这句原话是否逐字出现在这 4 轮里，对不上就整条丢掉。
   - 只记原文直接支持的内容，不设“至少记几条”；这 4 轮没有值得记的就一条不记。
   - 情感时刻用 `feel=True` 存，普通事实正常存。
   - 写入用 `hold`，原话放进 `quotes`，这几轮原文作为 `source_content`。
   - 失败不自动重试，屏幕上显示一行“这次没记成”和原因类别。这 4 轮在下一次补记时再试一次，最多两次。
5. **每记一条显示一行**：`📝 Peter 记下了：<标题或前 40 字>`，Peter 换成角色名。
6. **每轮自动想起**：发请求前，用 lan 这句话调 `breath_search(mode="automatic", with_ids=True)`。
   - 最多放 3 条进这一轮。Ombre 返回相关度时设门槛，不够格的不放；不返回相关度就只取前 3 条，并在 PR 里写明。
   - 放进去的内容单独作为一条 system 消息，开头写明“这是系统每轮自动带给你的记忆，不是 lan 刚说的”。
   - 一条都没有时，说明写“这一轮按 lan 的话没找到相关记忆，不要假装记得”。
7. **开场浮现**：启动时调一次 `breath()`，把结果作为带来源标注的 system 消息放进本次会话。
8. **当前状态说明跟着改**：`build_self_description()` 里“没有长期记忆”改成如实描述：有长期记忆、会自动记和自动想起、lan 能看能删。
9. **lan 能管**：
   - `/memory`：列出最近记下的条目（编号、时间、标题）。
   - `/forget <编号>`：让这条不再浮现。用 Ombre 自带的方式做，不直接删它的文件；先查清哪个操作能撤回，写进 README。
   - 记忆库就是 `data/<id>/memory/` 下的 Markdown，备份就是复制这个目录，写进 README。
10. **不自动删记忆**：本工单不做任何“过时就删”的逻辑。
11. **测试**：
    - 只用假模型，不调付费接口。
    - 覆盖：每 4 轮触发一次补记、原话对不上就丢掉、补记失败不重试且第二次再试、召回最多 3 条且带来源标注、中英文和换说法都能召回、没召回时的说明、两个角色的记忆目录互不相通、`/forget` 后不再被召回、补记请求计入预算。
    - 至少一个测试用真的 Ombre 跑在临时目录里。CI 装不动就在本机跑，把结果写在 PR 里。

## 不做

- Peter 自己调用记忆工具（自己决定记、自己去查）：下一张工单，需要工具调用。
- 工具成功和失败成为记忆：大块 4 之后。
- 向量检索和 Ombre 自带的模型调用。
- 自动判断过时、自动删除。

## 验收（lan 在 Windows 上做）

1. 拉最新 main，按 README 装好依赖。聊 8 轮以上，不说“记住”，随口提两三件自己的事（比如这周的安排、喜欢的东西）。屏幕上出现几行“📝 Peter 记下了…”，内容是你们真说过的，不是编的。
2. 关掉再开，提一句相关的事（比如“那个安排我有点紧张”），他自己接上，知道你在说哪件事。
3. 输入 `/memory` 能看到记下的条目；`/forget` 掉一条后，再提那件事，他不再自动想起。
