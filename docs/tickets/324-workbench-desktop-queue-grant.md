# 工单 324：工作台桌面调用排队与一次授权

## 目标

Peter 一次交给工作台的桌面任务能连续完成：模型并行发出的桌面调用依次执行，同一次聊天里只需批准一次桌面访问。

## 当前状态

- Lan 在正式 Peter 重试时，工作台里的桌面调用连续报错并被判“同一调用重复”而停止，还弹出多张桌面授权卡。
- 原因：并行调用被直接拒绝；每次工作台调用重新要授权。授权卡等待是否超过工作台调用等待上限未验证。

## 系统接入

- 入口：聊天与自主醒来的工作台任务；停止与恢复：排队调用在任务已停止或未知结果后返回“中断”，不执行动作。
- 权限：授权共用范围仅限同一次聊天请求，下一次请求重新询问；保存/发送/覆盖仍逐项审批。
- 费用、数据：不改动。状态可见：STATUS/HANDOFF。升级回滚：回滚即恢复为拒绝并行、每次授权。
- 真实环境：待 Lan 在 Windows 上体验。

## 验收步骤

1. 让 Peter “读一个公开网页，把摘要写进记事本，再切回来看一眼”，期间别碰鼠标键盘；只应弹一张桌面授权卡。
2. 确认工作台里的窗口列表、启动记事本等调用不再连续报错。
3. 任务中动一下鼠标，确认任务停止、不报成功。
