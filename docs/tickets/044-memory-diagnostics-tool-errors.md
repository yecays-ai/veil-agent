# 工单 044｜记忆诊断提示与工具拒绝原因

**基线：** `main` `8df2099c90bd6681ebfeab4f0302e7390a992e52`  
**分支：** `ticket/044-memory-diagnostics-tool-errors`  
**PR：** #81

## 目标

同一聊天轮次内，相同的记忆可见性诊断最多显示一次，同时无法确认的记忆仍不得进入模型上下文；确认可见的记忆必须继续进入真实模型请求。程序拒绝工具调用时，网页与 Peter 必须收到源头生成的同一句英文原因。

## 现状与证据

- Windows 实测截图显示同一条记忆可见性提示在多轮聊天前后重复出现。
- `Memory.refresh_visibility()` 对每个可见性未知的候选分别入队通知，并将该候选加入 `native_hidden`、清除缓存；`Memory.context()` 对普通、情绪和开场候选均会校验。因此收到提示的候选当轮确实被过滤，但截图不能证明其他记忆也都检索失败。
- 原先工具失败内容在 `model_tool_result()` 中被二次翻译或替换，网页和 Peter 得到的原因不一致。
- 仅用虚构数据验证；未访问真实聊天或记忆。

## 复用调研

已搜索 GitHub 中按会话轮次去重诊断及工具错误处理实现，并搜索本仓库。没有找到可直接复用且符合当前线程内通知队列、现有工具权限与安全边界的成熟实现。复用现有通知队列、工具结果送模链路与权限状态；不增加依赖。

## 修改范围

- `memory_agent.py`：按当前聊天轮次去重英文可见性诊断；未知可见性仍失败关闭。
- `long_tasks.py`、`memory_native.py`、`tools_agent.py`、`veil_agent.py`：在工具失败源头生成英文原因；`model_tool_result()` 不再改写失败结果；网页展示与送给 Peter 的内容相同。
- `tests/test_tools.py`：扫描上述源文件中拒绝/失败结果的返回字符串，确保不含中文；另验证模型结果与页面错误内容相同。
- 同一 PR 更新本工单、`STATUS.md`、`HANDOFF.md`。

## 验收

1. 多条虚构记忆可见性未知时，一轮最多出现一条英文诊断，且相应记忆标记不进入模型请求。
2. 同一轮中可确认可见的虚构记忆仍进入模型请求；下一轮可以再报告一次；隐藏记忆不进入模型请求。
3. 无效 `target_id` 的原因说明必须在本轮重新执行 `breath_search` 并使用其可见 ID。
4. 其他工具权限、参数、状态或保存失败使用源头的具体英文原因；模型与网页收到相同文本。
5. 原有工具权限、审批、参数校验和状态限制保持不变。
6. GitHub CI Windows/Linux × Python 3.11/3.12 通过，Claude 独立审查完成并处理必要功能与安全问题。
7. 合并后由 Lan 在 Windows 用虚构记忆验收正常召回、隐藏过滤、诊断提示及无效 ID 的纠正重试。CI 不代替真实聊天体验。
