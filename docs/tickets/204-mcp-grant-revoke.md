# 工单 204：撤销乌有乡直接调用授权

## 目标

Lan 在 MCP 设置中停用乌有乡后，Peter 的直接调用授权随之撤销；重新启用需再次确认。

## 当前状态

原保存逻辑用布尔或合并授权，明确提交 `false` 仍会保留旧授权。现有产品把启用乌有乡作为直接调用授权入口；此次沿用该入口，不增加权限系统。参考 [MCP Inspector 的服务授权设置](https://github.com/modelcontextprotocol/inspector/blob/e3217388c8590bcf6796fd8d0528a875ade1ac1f/docs/mcp-server-configuration.md)：显式关闭授权配置并持久保存；该项目的 OAuth 范围与 VEIL 的本地直接调用权限不同，因此只借用显式关闭的思路，不复制代码。代码与隔离测试完成，Windows 体验待验收。

## 验收步骤

1. 在 Peter 的 MCP 设置中启用乌有乡并确认授权，再点击「停用并撤销授权」；页面应显示授权已撤销。
2. 让 Peter 尝试使用乌有乡工具；调用应被拒绝，不能继续直接执行。重新启用时应再次弹出授权确认。
3. 关闭并重新打开 VEIL；乌有乡仍停用且授权已撤销，其他 MCP 服务保持原状。
