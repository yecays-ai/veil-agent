# 382 想起判官：聊到同一件事，他能自然想起共同经历，闲聊不被旧事打扰

所属格：A（记忆与人格连续性）。做完 lan 能多做的一件事：她随口说一句话（不用重复记忆里的原词），和这句话直接相关的共同经历能进到 Peter 的脑子里，影响他的反应；无关的闲聊不再被万能旧事打扰。她怎么验收：见文末。

## 现状（实验证据，2026-11-17）
Ombre 的自动检索是关键词检索加一条几乎打不开的向量旁路（向量相似度 ≥ 0.55 才能进候选，进了也排在杂音后面）。她日常说的话常常不含记忆里的词：「我又把一盆多肉养死了」找不到「养死仙人掌」；而「帮我把邮件改礼貌」却带出「GPT 道歉」「吵架」。单靠向量门槛分不开相关与无关（无关闲聊的最高相似度中位 0.51，相关句中位 0.58）。详见 `experiments/consolidate-367/out/batchG/recall-chain-report.md`、`judge-compare-report.md`、`judge-stability-report.md`（Lan 电脑，含私人聊天，不入库）。

## 改动
1. 新增 `recall_judge.py`：每条她的话，候选 = Ombre 的可见结果（≤5）∪ 向量最近的 5 条可见记忆（不含归档、隐藏、来源、digested、feel/plan/letter）。Peter 的后台模型（关思考、JSON 输出）只回答「哪几条与这句话直接相关，最多 2 条，不确定就不选」；它只读每条记忆的标题、标签和关键词行，不读正文，不涉及 Peter 怎么回复。
2. 判官说「没有」就是没有：不从 Ombre 回填。只有**技术故障**（超时、请求出错、返回坏 JSON、选了没给过的字母、没有向量、预算用完）才退回规则 A（工单 381）。连续 3 次故障暂停判官 5 分钟，避免后台故障拖慢每条消息。
3. 超时：判官最多多花 4.0 秒（`timeout_seconds`），超时算故障，这一轮照旧；首条消息之后正常多花约 1.1–1.5 秒（真实 Ombre + 真实模型实测）。她的话的向量在 Ombre 搜索的同时就开始算，所以不额外排队。
4. 独立开关：记忆页底部「想起判官：开/关」按钮，**默认开启**；也可在 `characters/peter/character.toml` 的 `[memory.recall_judge]` 里写 `enabled = false`（按钮的状态优先）。开关是一个文件（`data/<角色>/recall-judge.json`），每条消息都会读，**关掉立即生效**，回到规则 A，不修改任何记忆数据。
5. 费用：每条消息一次判官请求，记在「想起判官」类别（`/cost` 里单独一项，不占聊天），受每日/每月硬上限约束；超限算故障，退回规则 A。
不改：Ombre、记忆内容、冷却/去重/名额上限（判官选出的仍然走这些）、自主唤醒（唤醒没有她的话，不用判官）、短句借上文的二次检索、感受（feel）通道。

## 验收（lan 在 Windows 上做）
1. 更新并重开 Peter。打开记忆页，最下面应有一行「想起判官：开」和一个按钮。
2. 像平时一样随口说话，不要用记忆里的原词，例如：「我又把一盆花养死了」「今天又熬到天亮」「墙刚才晃了一下」。看他的反应有没有带着共同经历（不一定要讲出来，态度、判断里有就算）。
3. 随便闲聊几句（今天吃什么、问个常识）：不应该被旧事带偏。
4. 记忆页那一行会显示上次的结果（选了几条 / 觉得都不相关 / 没成功照旧）和今天花了多少。
5. 点「关闭想起判官」后再聊：回到原来的想起方式，一切照常；再点开启即恢复。
