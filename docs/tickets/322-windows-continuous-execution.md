# 工单 322：Windows 连续执行

## 目标

Peter 一次调用工作台，就能连续发现、观察和操作已授权的 Windows 软件，并在每次操作后根据实际 UIA 结果继续执行。

## 当前状态

工单 320 已合并，工作台已有任务本地、可撤销的 MCP 宿主动作通道。`windows_observer.py`、`windows_interaction.py` 和 `windows_discovery.py` 已实现窗口身份复核、敏感窗口保护、人工接管、权限审批和不确定结果停止，但尚未进入该通道。本单只接入现有 UIA 能力；不接入自绘界面的视觉坐标控制、画布或桌面图标操作。

## 验收步骤

1. 让 Peter 一次工作台任务打开记事本、输入一段文字、切回并观察内容；主聊天只显示一次工作台调用和最终结果。
2. 在操作前切换窗口或关闭记事本；确认 Peter 拒绝旧窗口或控件，不会操作其他窗口。
3. 操作中移动鼠标或按键；确认 Peter 停止后续桌面操作。对保存或覆盖操作，确认仍按原规则询问。
