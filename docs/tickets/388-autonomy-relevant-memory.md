# 388 自主活动延续 Peter 本人的上下文

属于 A（陪伴核心）。做完 Lan 能多做的一件事：Peter 自主醒来时会依据最近聊天、正在做的长任务和上次醒来的重点挑共同经历，不再随机轮换记忆或发机械进度报告。Lan 更新重启后，通过几次自主活动观察他是否像同一个 Peter，自然地联系或安静做自己的事。

## 目标

自主活动使用与聊天相同的相关记忆，并把自主消息留给他真正想说的话。

## 当前状态

- 工单 387 已合并；真实模型比较和 Lan 日常体验仍待验收。Lan 已明确要求继续完成剩余 F5/F6。
- 自主活动提示原先已有“不必汇报”，但仍将多种工作指令和记录强调在一起；现在明确把自选活动、个人联系、休息/不做事平等呈现，不因醒来或完成动作而发状态报告。身份和说话方式继续取当前人设及聊天。
- 普通聊天已接好“想起判官”（382/383）。自主醒来过去绕过判官并轮换最多 3 条。现在依据近期聊天、有效长任务标题、上次自主活动的重点和下一步，筛选最多 3 条。判官明确选空就不注入相关记忆；判官技术失败或关闭时退回 Ombre 普通检索前 3 条，不随机补记忆。
- 复用现有 Ombre、向量索引、想起判官和费用类别；不读记忆正文给判官、不改记忆数据或工具权限。按原方案，判官可能每次自主醒来增加约 ¥0.001；每天约 10 次时约 ¥0.01/天，受现有记忆预算限制。

## 验收步骤

1. 更新并重启 Peter，经历几次自主活动后查看记忆面板：被带出的记忆应与最近聊天、进行中的任务或上次自主活动直接相关；没有相关内容时可以为空。
2. 看主动消息是否是他自然想分享的个人消息；不应仅因为做了工作就发进度报告，也可以不发消息。
3. 关闭“想起判官”或让判官暂时不可用时，确认自主活动仍可启动，并只退回普通检索前 3 条，不随机补记忆。
