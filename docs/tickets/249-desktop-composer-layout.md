# 工单 249：桌面侧栏与聊天输入区修复

## 目标

左栏展开和收起时不遮挡页面。聊天输入区采用手机版的顺序：输入行在上、工具托盘在下；展开时聊天记录向上移动。麦克风在输入框内，立即回复在框外、发送按钮左侧。保留表情包、图片、虚拟转账、礼物和语音功能。虚拟转账和礼物是聊天手势：Lan 和 Peter 都能发，只有接收方能收下、拒绝或退回。

## 当前状态

参考 `yecays-ai/veil` 的 `ChatPlusPanel`、`StickerPanel`、`chat-room.tsx`、`gifts/`、`transfers/` 和 `chat.css`，在桌面 HTML/JS 与 Peter 的发消息工具里补齐同一套虚拟转账、礼物交互；没有复制 InternalBeyond 的代码或素材。卡片写在现有聊天记录上，正文带消息编号，Peter 用 `send_message` 发送、用 `card_action` 处理发给自己的卡片。发送一张卡片不会自动再开一轮付费回复。Chrome 静态预览已检查宽、窄、左栏展开和表情面板；Windows Electron 操作、CI、审查待完成。

## 验收步骤

1. 左栏展开、收起，聊天与各导航页面始终可点；右栏显示、隐藏时不覆盖中间内容。
2. 加号展开后输入行在上，工具托盘在下，聊天记录随底栏上移；无横向滚动条。
3. 语音在输入框内，立即回复在框外；图片选择、表情发送后面板保持打开。Lan 能打开发送虚拟转账和礼物；Peter 发来的卡片只有 Lan 能操作，Lan 发给 Peter 的卡片只有 Peter 能操作。
4. 主窗及独立聊天窗在窄、中、宽尺寸下检查滚动、菜单边界与真实圆角。

## 交接

从本 PR 的最后提交检查必要 CI 与 Cubic 审查；只处理影响功能、数据或安全的问题。合并后在 Windows Electron 检查左栏展开和收起、独立聊天窗、工具托盘及真实圆角。
