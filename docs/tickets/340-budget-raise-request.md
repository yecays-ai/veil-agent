# 340 任务超出预算时 Peter 向 Lan 申请加预算

## 目标
唯一的硬限制是预算上限。Peter 觉得一个任务要花得比默认多（默认工作台每次 ¥0.5），就自己申请；Lan 在同一张审批卡（网页和 QQ 都会收到）上同意才生效，不同意任务不运行，也没有任何自动提高。

## 行为
- `workbench` 工具多一个可选参数 `budget_cny`：这一次任务的费用上限（元）。不填就是默认。
- 填得比默认高：弹一张卡，写明从 ¥X 提到 ¥Y、任务是什么。同意后这一次任务用新上限，用多少花多少；下一次任务回到默认。
- 如果今天或本月剩余额度装不下，同一张卡里写明并在同意后把今天的总上限临时提高差额，只管今天（重启后回到配置值）。
- 任务因单次上限停下时，报告里提示 Peter 可以带更高的 `budget_cny` 重跑。
- 自主活动（没人在）不弹卡，仍用 ¥0.3/次的上限；自主每日 ¥3 和每次 ¥0.25 的上限不变。
- 单次申请的合理性上限 ¥50，只防写错，真正的把关是 Lan 点同意。

## 验收步骤
1. 对 Peter 说一件明显较大的活（比如“把某个开源项目整个读一遍并写总结”）。
2. 他申请更高上限，卡上写着多少钱、为什么；同意后任务开始，不同意任务不运行并告诉你。
3. 在 QQ 上发起的同样会在 QQ 收到这张卡。
4. `/cost` 里今天的上限在批准后显示新数。
