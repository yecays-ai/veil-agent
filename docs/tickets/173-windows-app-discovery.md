# 工单 173：自主发现与探索 Windows 软件

## 目标

Peter 可在正常聊天或自主唤醒时自主发现 Windows 电脑上安装的普通桌面软件，安全启动感兴趣的软件、观察界面控件并尝试受控的探索操作，过程记录在现有活动日志中，无需 Lan 事先逐一配置白名单。

## 当前状态

Windows 软件启动与交互目前依赖静态配置 `windows-apps.toml`。借鉴开源启动器（Microsoft PowerToys Run 与 Flow Launcher，MIT 许可）的成熟思路，通过开始菜单（User 及 Common Programs）与注册表 App Paths 解析已安装普通桌面应用，排除安装卸载、脚本解释器、系统提权等危险入口；复用现有 `windows_interaction.py`、`windows_observer.py`、UIA、窗口身份校验、人类输入优先与活动记录；实施发现、启动、观察、交互分级权限，程序层拦截文件对话框与高危控制。自动检查与 Windows 实机体验分别记录在 `STATUS.md`。

## 验收步骤

1. 在未将“画图”或“计算器”写入 `windows-apps.toml` 的情况下，在聊天或自主唤醒中让 Peter 自主发现已安装桌面应用，确认他能识别到该软件并成功启动、识别实际窗口。
2. 观察 Peter 观察窗口控件并完成至少一次安全操作（如工具选择或切换标签），测试尝试危险控件、文件对话框或移动鼠标/敲击键盘时程序能可靠拒绝或立即停止。
3. 在活动记录中查看完整的发现、启动、观察与操作记录，重启服务后记录仍可查，原有白名单应用与系统文件不受影响。
