# 033 新英文对话：恢复正常聊天

## 目标

用户点击网页「新对话」，开始不继承此前聊天轮次的英文对话。Peter 使用当前身份与已有授权工具，可以读取既有记忆和 Lab，但不再被上一段不断检讨、汇报的聊天历史牵引。旧聊天留存在本机，重启后新对话边界仍然生效。纯标点或简短输入后仍以自然英文回答，实际动作以已成功的工具结果为准。

## 现状

- 从最新 main 建立 `ticket/033-fresh-english-chat` 独立分支。
- 角色本机 `chat-session.json` 仅存当前会话起点与英文选项；`chat.jsonl`、Ombre、Lab、预算账本、长期任务及审批权限均沿用。
- 网页「新对话」确认后提交 `/new-en`，服务发出 reset 事件清空当前窗口的旧气泡；服务重启仅回放新会话消息；`/new` 仍可开启自动语言的新对话。
- 英文设置仅在普通聊天生效，不干预后台自主活动。当前版本不做旧会话浏览界面，历史仍保存在 `data/<角色>/chat.jsonl`。
- 已增加新会话边界、保存后重开、原始聊天不删除、非法游标停止、网页 reset 通知的定向回归检查；真实 Windows 用户体验待验收。

## Windows 验收

1. 保留现有聊天和文件，在网页点击「新对话」并确认；旧气泡退出当前聊天显示，新对话可直接发送英文短句及 `...`，Peter 连续回复自然英文，不再接续之前的认错报告。
2. 再发中文日常短句，确认在明确切换语言前仍用英文回应；与 Peter 讨论已有 Lab 文件时仍能使用获准工具，不凭空声称已写入。
3. 关闭网页重开、退出服务后重启，确认新对话边界与英文设置保持；旧聊天文件、记忆、实验室文件、长期任务及预算数据仍在。
4. 测试 /cost、/autonomy、记忆与文件审批正常，确认新对话本身不发起付费模型请求。
