# 工单 392：去掉界面上的 AI 味（解释、监控感、堆叠设置、提示刷屏）

- 属于：阶段顺序第 6 条「电脑与手机 UI 统一小修」的电脑端部分（不在 A/B/C1/C2/C3/V/D 五条线里）。
- 做完 Lan 能多做的一件事：打开 VEIL 就像打开自己的桌面程序，不用先读四行说明才知道每项是干什么的；同一句提示不会再连刷二十条。
- 她怎么验收：下面「验收步骤」三步，在 Windows 上手动做。

## 目标

界面不再像数据后台：没有解释型文案、设置项默认收起、原生勾选框换成开关、同一提示合并成一条、启动页只留一句。

## 当前状态

- `desktop/chat.html`：设置页 `#more-view` 每个控件下面跟一条 `.setting-hint` 常显解释；卡片平铺，没有折叠。
- `desktop/chat.js`：`notify()` 直接 append，同内容不合并，最多会连刷十几条；同类失败（如找不到 QQ）每次都独立弹一条。
- `desktop/desktop-visual-system.css`：208px 侧栏 + 64px 顶栏，顶栏常显「自主活动 / 下次唤醒 / 模型切换」三组状态，视觉上像监控台。

## 已做

- 文案总攻（除聊天页）：`chat.html` / `chat.js` 里 248 条解释性文案改成短句，映射见 `ui-preview/copy-rewrite.json`。例：
  - 「多轮搜索、阅读和记忆查询交给单独模型；只读工具，费用计入共享上限。留空可关闭。」→「留空关闭」
  - 「Ombre 给记忆打标签、整理短期便签用这个。换了以后，完全退出 Peter 再打开才生效。」→「重启后生效」
  - 「自动整理经历：关（不会再写新的，也不会把近几天的放进聊天；已经写下的还在，可以逐条删）」→「自动整理经历：关」
  - 「你改过这条之后，他又改了它。不满意可以在下面「历史版本」里恢复你的版本，或者锁定。」→「他又改了，可恢复或锁定」
  - 语音样例那段保留格式说明（「>」是你、空行分段），那不是解释功能，是照抄的写法。
- QQ 与同类系统提示：来自后端事件的 `notice`，同一句 6 小时内只显示第一条；工具提示走 `addTrace()`，不受影响。
- 右下角 toast：同一句 30 秒内只弹一次，最多 3 条，不显示计数。
- 玻璃皮：新增 `desktop/glass.css`，只叠在侧栏、顶栏、输入框、弹层；令牌全在文件顶部；`custom-style` 仍在最后加载。
- 发送键图标：`arrow-up` → 纸飞机（`icons.js` 新增 `send`）。

## 待做

- 设置页：`.setting-hint` 改为按需出现（悬停或点 `?`），不常显。
- 设置页：每张卡片收成可展开分组，默认只开第一张。
- 开关：`input[type=checkbox]` 换成开关样式，不再出现原始勾号。
- 启动页：去掉状态列表，只留一句短语。
- 顶栏：三组状态收进一个面板，默认不占顶栏。

## 验收步骤

1. 打开 VEIL：启动画面只有一句，没有状态行和指标。
2. 设置页：每张卡片收起，点标题才展开；没有常显的解释段落。
3. 制造一次连续失败（例如把 QQ 通道断开）：屏幕上只有一条提示，带 ×N，不再连刷。
