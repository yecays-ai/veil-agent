# 工单 023：自主活动记录带入聊天

## 目标

自主活动完成后，Peter 在后续聊天中能依据最近一次活动记录回答“下午做了什么”，且 `/cost` 正确汇总所有角色的自主花费。

## 当前状态

自主活动单独保存在 `data/<角色>/autonomy.jsonl`，普通 `Chat.send` 未将最近一次活动摘要带入请求；`Budget.display` 只按 `peter` 统计自主花费；结束原因也将名字写死为 Peter。复用调查：GitHub 搜索“agent background activity chat context”未找到适合本地多角色 VEIL 的成熟实现；现有 `Chat.send(extra_context=...)` 和按角色存储的自主活动日志已满足接入点，因此沿用现有路径，不引入新框架或依赖。将每次聊天的最近一次摘要限制在约 500 tokens，按输入 ¥2/M、每天 20 次聊天估算，未命中缓存约增加 ¥0.02/日；lan 已确认接受。

## 验收步骤

1. 等 Peter 完成一次自主活动后，在后续聊天问“下午做了什么”；确认回答能依据该次记录中的决定、工具或 Lab 产出。
2. 让 Ghost 完成一次自主活动，再查看 `/cost`；确认自主花费包含 Ghost，不被误算成聊天。
3. 确认空自主记录时聊天正常，Peter/Ghost 各自身份和记录隔离不变，`/memory`、文件审批与费用上限仍有效。
