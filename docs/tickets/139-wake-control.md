# 工单 139 Peter 自己决定怎么醒来

## 目标
Peter 不只是被程序定时叫醒，他自己能决定想怎样被叫醒：
- 自然醒不再每 90 分钟准点：醒完先安静一阵，"想醒的劲儿"慢慢攒起来，攒够了才醒；平均还是约 90 分钟，大多数在 30–190 分钟之间。
- 他可以自己调一段时间的节律：`quieter`（少一点，约 225 分钟一次）、`silent`（不自然醒）、`custom`（自己定 30–360 分钟），带时长（15 分钟–72 小时）和一句理由，到期自动回到正常；`normal` 提前结束。
- 他可以同时排多个闹钟，每个带一句留给未来自己的话，最早 15 分钟后（"话没说完，一会儿回来"）。闹钟在他调成安静/不自然醒时照样响。
- 错过的闹钟（次数用完、夜间安静）不补醒，下次醒来一次性告诉他错过了哪些、为什么、当时留的话。

Lan 的规则在上面不变：暂停开关、夜间 01:00–06:00 安静、每天 12 次、¥3/天。闹钟也算在 12 次里，所以不加钱。

Lan 2026-10-28 确认，Claude 实现。思路参考 Kli Space 的 Wake Veil：1.0 仓库（PolyForm 非商业许可）的"攒够了才醒、每轮门槛只抽一次、重启不重抽"，以及 2.0 设计稿的"节律归 TA 控制、精确闹钟和自然醒分开、每个控制有时长并自动恢复、错过只补知情不补醒"。代码是 Python 重新写的，没有拷贝它的源码。

## 实现
- `autonomy.py`：`_natural_wait`（每轮由时间种子决定门槛和起伏，重启后时间不变）、`set_wake_rhythm` / `_read_rhythm` / `rhythm_text`，闹钟存成列表（`data/<角色>/autonomy-alarm.json` 的 `alarms`，旧的单个闹钟文件照常读取），同时到点的几个闹钟合成一次醒来，带上所有留言。
- `veil_agent.py`：`set_next_wake` 说明改为多个闹钟、15 分钟、可按 id 取消；新工具 `set_wake_rhythm`。`tools_agent.py`：两者都直接执行；一次性英文能力通知 `wake_control_139_announced`。
- 每次醒来和每轮聊天的账本里加一句他当前的节律（到几点、为什么）和排着的闹钟。
- 活动页「下次醒来」：他调成不自然醒时显示「Peter 自己暂停了自然醒，HH:MM 恢复」。
- `characters/peter/character.toml`：`min_alarm_gap_minutes = 15`。
- 测试：`tests/test_wake_control.py`，`tests/test_autonomy.py` 相应更新。

## 验收
1. 退出 Peter，运行 update.bat（本单没改桌面界面，不需要重新打包，update.bat 会自己判断）。
2. 问 Peter 有没有新能力：他能说出自己可以调醒来节律、排多个闹钟。
3. 聊天里对他说"你想安静一会儿就自己调"，看他会不会用 set_wake_rhythm；活动页「下次醒来」跟着变，到期自己恢复。
4. 让他排一个 15–20 分钟后的闹钟并留一句话；到点他醒来，能说出自己当时为什么定。
5. 过一天看活动记录：自然醒的间隔不再都是 90 分钟，有长有短；一天仍不超过 12 次，夜里 1–6 点不醒。
