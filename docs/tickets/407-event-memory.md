# 工单 407：事件记忆（写入、故事、召回、页面、后台修复）

- 格：A（记忆与人格连续性）
- 做完 lan 能多做的一件事：同一件事多次保存只形成**一段经历**（一条记忆 + 一份完整故事），她在「记忆 · 经历」里能看到故事、阶段、证据和旧版本；不同的事不会因为同一天或几个词就被并在一起。
- 她怎么验收：打开开关后，用三种不同说法聊同一件事，只出现一段经历；再聊一件不相干的事，出现第二段；点开经历能看到完整故事、每段和证据；隐藏一条后，时间线读不到它。

## 目标

同一事件跨多次保存只形成一条 Ombre 记忆（正文是 400 字摘要），完整故事、阶段、证据和旧投影留在本地事件库；新增只读 `memory_timeline` 和「记忆 · 经历」页；事件级召回不重复占名额；后台整理负责重试失败投影和合并可证明的重复。默认关闭（`[memory.events] enabled`），关闭时行为与现在完全一致。

## 当前状态

- 保存：`memory_native._hold` 一次保存 = 一条记忆；同一天三次保存靠 `link_to` 串，形成三条。
- 事件对象：长期记忆层没有；`event_id` 只出现在短期便签和 UI。
- 证据：`tools.jsonl` 只存截断摘要；`request-snapshots` 只保留 40 轮。
- 相关代码：`memory_native.py`、`memory_agent.py`（召回）、`experience_memory.py`（后台）、`web_agent.py` / `desktop/chat.js`（页面）。

## 本单范围

1. 事件库：`events.jsonl`（含完整 `story`）、`event-stages.jsonl`、`stage-evidence.jsonl`、`event-versions.jsonl`、`event-review.jsonl`、`event-ops.jsonl`。
2. 保存时归组：Ombre 检索命中的记忆反查事件、共享名字/物件、同日、未关闭事件、以及聊天/自主/工具原始记录里的同实体提及；不确定时建「暂定事件」并进复核，不硬并。
3. 一条事件一条 Ombre 记忆：正文 400 字摘要；完整故事落盘，`memory_timeline` 读故事 + 阶段 + 证据。
4. 证据随阶段落盘（聊天/自主/工具最近记录），不依赖 request-snapshots。
5. 召回：同一事件的多条记忆只占一个名额（`memory_agent._event_map` + `duplicate`）。
6. 页面：「记忆 · 经历」列出事件、点开看完整故事、阶段、证据、旧版本。
7. 后台：`experience_memory` 每次整理时重试 `dirty` 投影，并合并共享同一 Ombre 记忆的事件（只做可证明的合并）。
8. 开关：`[memory.events] enabled`，默认 false；关闭时旧路径原样。

**不在本单**：194/现有旧记忆的重新归组与逐条核对（工单 408）。

## 验收步骤

1. 在 `character.toml` 加 `[memory.events] enabled = true`，重启。
2. 用三种不同说法聊同一件事；记忆列表的「经历」里只有一段，点开有完整故事、阶段和证据。
3. 再聊一件不相干的事；出现第二段，不和第一段合并。
4. 把其中一条记忆在 Ombre 页面设成隐藏；`memory_timeline` 和「经历」里读不到它。
5. 关掉开关重启；保存行为回到现在。

## 接入检查

- 入口：`hold`；开关打开且没有 `target_id`/`link_to` 时走事件层（pinned/importance 仍传给新事件的那条记忆）。
- 停止与恢复：关开关即回旧行为；投影失败时阶段已落盘、事件标 `dirty`，后台整理重试；不会退回旧 `hold` 重复保存。
- 权限：仍是角色自己的记忆；`memory_timeline`、页面只读；锁定/隐藏/删除的记忆不改写、不复活、时间线读不到。
- 费用：本版不新增模型调用（故事是确定性拼接，不压缩细节）。
- 数据：事件库在 `data/<角色>/`；旧记忆不动。
- 状态可见：保存返回 event id；页面「经历」；时间线工具。
- 升级回滚：关开关或删事件库即可。
- 真实环境：假数据测试；真机开关由 lan 打开。
