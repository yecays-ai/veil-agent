# 工单 177：预算残留、用量超限、聊天页卡死、图标快照与价格输入

## 目标

- 进程在回复途中被杀或崩溃后，没结算的预留不再永久占用每日、每月和自主额度。
- 接口报告的用量略超配置上限时，服务继续运行，并如实记账。
- 聊天页遇到一条无法显示的消息时，其余消息照常显示，不显示「连接中断」，按钮不变灰。
- 桌面整理一定先保存有效快照；没读到图标就不移动任何图标。
- 添加模型时，价格可以填 0.001 这类小数。

## 现状

见 `STATUS.md`。

## 验收步骤

1. 退出 Peter，运行 `update.bat`，重新打开。
2. 打开「/cost」或花费页，确认「待核对预留」为 0（旧的未结算预留已被处理）。
3. 普通聊天回复进行中时，在任务管理器杀掉 Python 进程，重新打开：「待核对预留」为 0，这次请求按预留上限记为已花费一次（今天的花费多出这一笔），自主额度不被占用。
4. 更多 → 模型：添加一个按 token 计费的模型，输入价格填 0.001，保存成功。
5. 用之前会触发「接口用量超过配置边界」的模型（grok-4.6）聊几句，服务不再退出；花费页能看到这次记录。
6. 让 Peter 整理桌面图标，再点恢复：恢复回整理前的位置。
