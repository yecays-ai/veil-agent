# 工单 137 桌面 UI 提示与连续重新生成

## 目标

Lan 可以连续重新生成同一轮回复直到满意，并在桌面端使用不挡视线的通知、隐藏的桌宠调整点、可铺满工作区的聊天窗及可取消的录音。

## 当前状态

连续重新生成时，新回复使用了不同的 request ID，程序因此找不到原用户消息；生成记录需保存原用户消息 ID，并兼容旧记录。桌面端调整点默认可见，语音识别错误状态不会自动消失，录音没有可见的删除入口，扩展聊天窗只设为固定尺寸；普通通知以浮层提示。改动位于 `veil_agent.py`、`desktop/chat.html`、`desktop/chat.js`、`desktop/chat.css`、`desktop/main.cjs` 与 `desktop/pet.css`。复用现有 MediaRecorder 取消通路和 `workAreaAt` 屏幕工作区计算；参考了旧仓库的功能描述，但其 React/Next 语音实现不适用于本桌面端。

## 验收步骤

1. 更新 Windows 桌面程序，在同一条 Peter 回复上连续点“重新生成”数次；每次都应继续基于原始用户消息生成，且最终只留下最新回复。
2. 打开桌宠时确认四个调整点默认隐藏、鼠标移到桌宠上时可见；点聊天窗“铺满可用桌面区域”，确认窗口占满屏幕工作区且顶部工具栏仍在。
3. 在输入区开始录音，点“删除”确认录音取消且没有发送；触发语音识别错误，确认提示约三秒后消失；普通工具通知应留在聊天记录中，不弹出独立窗口。
