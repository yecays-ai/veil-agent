# 工单 130 Codex 提醒不再召回长期记忆

## 目标
Codex 跑完或卡住时，Peter 写给 Lan 的提醒不再先搜长期记忆。

## 现状
10-26 到 10-27 的 `context-log.jsonl` 里有 30 次 Codex 提醒，每次都带着约 6700 字召回的长期记忆，但提醒只需要事件信息。

## 改动
`Chat.send` 在 `codex_watch_mode` 时不调用 `memory.context`，本轮记忆编号为空；聊天、QQ、自主活动、瞄一眼不变。背景库和短期便签照旧。

## 验收
更新后等一次 Codex 提醒，上下文页这一行没有召回的记忆，提醒照常送到。
