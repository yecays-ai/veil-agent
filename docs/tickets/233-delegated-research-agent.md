# 工单 233：委派只读搜索与阅读

## 目标

Peter 可以把多轮搜索、网页/文件阅读和记忆查询交给单独选择的低价模型，自己保留最终判断和回复。

## 当前状态

现有聊天模型循环在 `veil_agent.py`，统一工具与 MCP 通过 `Chat.tool_schemas()` / `_execute_tool_call()`，模型按用途由 `model_settings.py` 选择，费用由共享 `Budget` 写入 `costs.jsonl`。本工单沿用这些入口；不引入 Agent 框架。子 Agent 仅获得固定只读工具白名单（网页、文件、记忆、GitHub 只读 MCP，以及实验中人工核验过的花园论坛只读 MCP 名单），最多 6 次模型请求、12 次工具调用、90 秒，不能递归委派或发送消息；其费用与聊天共用每日/每月总额，在账本标记为 `delegate`。

## 验收步骤（Lan 在 Windows 上做）

1. 在“更多 → 模型”选择“委派任务”模型，让 Peter 搜索并阅读多个来源后总结；活动记录应显示委派和实际只读工具调用。
2. 用 `/cost` 确认当天总额包含委派费用，且显示“委派任务”单独分账；关闭委派后，Peter 不再调用子 Agent。
