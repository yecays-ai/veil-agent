# 工单 404：自动检查与长期维护（四部分之四）

## 目标

防止以后新增提示词再次写死，并保证软件更新不会覆盖 Lan 的修改；更新后能看出「默认变了、你改的那版还在用」。

## 本单做了什么

- **默认指纹**：保存覆盖时记录当时的默认文本指纹（`persona/instructions/.base.json`，不进仓库）。
  之后默认文本被更新时，页面给这一条标「默认已更新」，正文里写「你这一版仍在用」；顶部显示「你改过 N 条，其中 M 条默认已更新」。
- **守卫扩到中文**：扫描模型相关模块里 40 个汉字以上、带句末标点的字符串；连同英文长句、工具参数文本一起进
  类型化清单（新增原因 `ui-error:`），名单只许减少。
- **新增测试**：
  - 合成一条新的英文提示词 → 必须被扫描抓到且不在清单里；
  - 合成一条长的中文提示词 → 同样被抓住；
  - 默认文本改了、覆盖还在 → `default_changed` 为真且覆盖内容不变；
  - `persona/instructions/` 确实被 git 忽略、`update-main.cmd` 不碰它。
- 说明文档补上「更新后你的修改还在」和默认变化的处理方式。

## 不做

- 不做版本历史、差异对比、恢复默认（Lan 2026-11-20 明确不要）。
- 不自动改写默认文本。

## 验收（Lan）

1. 打开「指令」，顶部显示「你改过 N 条」。
2. 如果你改过的一条，后来代码里的默认也变了：那一条出现「默认已更新」，正文仍是你写的。
3. （开发侧）在代码里写一条新提示词不登记，测试失败；登记后页面自动出现。
4. 更新软件后，你保存的措辞仍在。

## 评审后的修正（Chat，2026-11-20）

- 保存覆盖后计算默认指纹改为独立、可失败的步骤：默认文件读不到时，保存仍算成功，不误报失败。
- 旧覆盖（#401/#402 时期保存、没有 `.base.json`）在第一次读状态时用**当前默认**补一个基准，
  只写指纹文件，不改写覆盖正文；之后的默认变化能正常提示。
- 补两条回归：默认缺失时保存成功；旧覆盖补基准且正文不变、后续默认变化能被发现。
