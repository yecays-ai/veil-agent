# 工单 131 消息操作和回忆界面

## 目标

让 Lan 在消息右键、引用、查看回复关联记忆和发送语音时，获得与小手机一致、清晰易用的体验。

## 当前状态

桌面消息操作已有功能，但菜单图标是手写路径，选中消息没有浮起，引用直接写入输入框，关联记忆显示原始元数据且多列挤压。参考小手机消息操作、引用、记忆面板和点击录音方式，复用现有消息、语音与记忆接口；图标使用 Lucide 官方文件（ISC，许可随代码保存）。记忆卡片显示该回复关联的前五条当前记忆内容，不包含 Journal。

## 验收步骤

1. 右键一条消息，确认选中的消息浮在虚化背景前，八个图标清晰，原有操作仍可用。
2. 点击 Quote，确认输入区显示可取消的引用，发送后引用内容与回复清楚分开；重启后旧聊天和新消息仍可阅读。
3. 点击 Peter 消息的 Memory，确认每条卡片横向显示时间、少量标签和正文；无记忆或读取失败时有明确提示。
4. 输入区用 T 进行语音转文字、用图片图标选图；点击输入框内麦克风开始录音，再点一次直接发送语音，鼠标移开不取消。
