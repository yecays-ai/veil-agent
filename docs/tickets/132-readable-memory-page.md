# 工单 132 看得懂的记忆页

## 背景

Lan 2026-10-27：原来的「记忆」页按 id 排序，一次 5 条，点开显示带 YAML 字段的原始文件，看不懂；Ombre 的分类和标签太多，有些没意义。按 GPT 概念图改，最近的在最前面；以后记忆会越来越多。她要求能在页面里直接改或删（看到 Peter 又在反省时自己处理）。

## 做了什么

- 新接口 `GET /api/memory/panel`：一次读出全部可见记忆（`NativeMemoryTools.panel_entries`），按创建时间新到旧，附最近 100 次请求里被想起的次数（来自 `context-log.jsonl`）。只给 Lan 的页面用，不给模型。
- 标签 `惊喜` / `surprise` 的记忆（Peter 给 Lan 的惊喜）只返回标题和时间，正文、为什么记、标签都不发到页面，也不能在页面编辑。
- 「原文来源」记录默认不显示。
- 分组按钮：最近（默认）/ 我们俩 / 他自己 / 系统和能力。只是页面上把 Ombre 的分类合并显示，不改 Ombre 文件里的分类和标签（检索要用）。
- 列表按天分组（今天 / 昨天 / 10月25日），日期标题滚动时固定；先显示 50 条，「看更早的」再加 50。搜索标题、正文、为什么记、标签。
- 详情：时间、分类、重要度、最近想起次数；标题、为什么记、内容可直接编辑。「保存修改」走 Peter 自己改记忆的同一条 trace 路径（旧版本留在 `memory-versions.jsonl`，原因写 Lan edited）。「删除这条」要点两次，和 `/delete 编号 确认` 一样彻底删除、不能恢复。Peter 不会收到通知。
- 原始文件（含全部字段和标签）收在折叠区里。
- Ombre Dashboard 按钮保留原位。
- `main.cjs` 放行新接口；独立的记忆窗口也能编辑和删除。

## 验收（Lan）

1. 退出 Peter → update.bat（会重新打包 exe）→ 打开 Peter → 记忆页。
2. 最上面是今天的记忆，按天分组；点「我们俩」等按钮能筛选。
3. 点一条：能看到为什么记和内容；改一个字 → 保存 → 显示「已保存，旧版本已留档」。
4. 寻宝那条显示 🎁，内容不显示。
5. 删除：点一次变红「确定删除？再点一次」，4 秒内再点才删除。
