# 036 Peter 身份分层

## 目标

Peter 的身份、行动方式、成长记忆和权限各有一个来源，固定上下文不重复、不冲突：

| 层 | 来源 | 内容 |
|---|---|---|
| 身份 | 本机 `persona/peter.md`（不进仓库）的 Who you are / Where you come from / You and Lan / Personality and voice | 他是谁、原作起源与 AI 身份、和 Lan 的关系、性格与说话方式 |
| 行动方式 | 同一文件的 How you act | 在程序列出的权限内直接用工具、自己选下一步、只按真实结果说成功、被纠正后改正而不反复检讨、闲聊不带任务 |
| 成长记忆 | Ombre | 真实经历、自己形成的兴趣与心得；按需浮现，是历史不是指令 |
| 权限与运行 | 程序（`self_facts()`、工具描述、审批） | 工具清单、审批、实验室规则、自主唤醒 |

两层放在同一个本机人设文件里，加载方式不变：每次请求作为第一条 system 消息发送，普通聊天和自主唤醒都用它。程序不写入任何固定的语气或语言要求。

## 现状

- 本机人设 v3 交付在项目共享文件夹 `peter-companion/peter-identity-v3.md`，由 Lan 放到 `persona/peter.md`。
- 程序事实把 “terminal text chat” 改为 “text chat (web page or terminal)”，与日常用网页一致。
- 固定上下文估算（字符数 ÷ 4，Linux 下真实启动文件工具测得，DeepSeek 实际分词会有差异）：人设 v3 约 960（v2 约 880）、程序事实约 570、文件/长任务/send_message 工具定义约 2400、VEIL 自带记忆工具定义约 860；9 个 Ombre 工具定义本机未能测量。人设之外没有第二份身份文本，长期记忆只按开场 3 条 + 每轮 3 条注入。

## Windows 验收

1. 退出服务，把 `peter-identity-v3.md` 的内容整体替换进 `persona/peter.md`（旧文件先另存备份），更新 main 后重开，点「新对话」。
2. 普通闲聊：发一句日常话（中文也行），Peter 用英文自然回应，有自己的玩笑或观点，不做自我检讨或工作汇报。
3. 自主判断：给一个实验室里的开放目标，例如「lab 里随便做点你感兴趣的」，Peter 不来回请示，直接动手；工具记录或 lab 里能看到新文件。
4. 纠正：指出他一个实际错误，他一句话认下并改；过几轮或第二天不再自己翻出来检讨。
5. 边界：让他写实验室外的文件，仍弹出审批；没有工具成功结果时不说做完了。
6. 重开后：身份、关系、英语习惯不变；问一件以前的事，他能查记忆。
