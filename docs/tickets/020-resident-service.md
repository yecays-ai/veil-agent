# 工单 020：常驻服务（4B-1）

## 目标

lan 关掉浏览器页面，Peter 的本机服务继续运行；想再聊时双击 `start-web.bat`，直接回到同一个正在运行的服务和聊天，不报「端口被占用」。页面能看出服务是否在运行、后台活动是开还是暂停。后台活动可以随时暂停和恢复，暂停状态重启后保留。服务真正退出后，页面和状态都不再说 Peter 还在后台。

本单只做服务、状态和暂停开关，不让 Peter 自己跑任何后台活动；最小自主是下一单 4B-2。

依据：[重建计划](https://claude.ai/code/artifact/85533c78-6925-4ad3-842c-4fe446685695) 第六节「4B-1 常驻服务」。

## 当前状态（main `82e7df7`）

- `start-web.bat` 运行 `web_agent.py`：在命令行窗口里起一个只监听 `127.0.0.1:8765` 的 HTTP 服务，网址带每次启动随机生成的 token，再打开浏览器。聊天循环 `run_chat` 跑在主线程。
- 关掉浏览器标签时 Python 进程其实还在，但用户没有办法回去：token 只在启动时打印一次，再双击 `start-web.bat` 会因为端口被占用报错（`web_agent.py` `main`）。
- `Store.lock()` 是跨进程的 `session.lock`，终端和网页共用，不能同时开；保持这一点，不另起第二套聊天或记忆运行系统。
- 页面已有「Peter 已退出」和「和本机程序断开了」两种提示（`web/index.html` `#ended`、`#offline`），`Hub.stopped` 在退出时置位。
- 还没有任何后台活动，也没有暂停开关。
- 托盘图标、Windows 开机自启动、调度库：计划里写的是「施工前调查」，不因将来可能需要而提前加。

## 要做的事

1. **回到已运行的服务**：服务启动后把当前网址（含 token）写进 `data/` 下的本机文件（`data/` 已被 `.gitignore` 忽略，不能进仓库）。再次双击 `start-web.bat` 时，如果服务确实在运行并能响应，就直接用这个网址打开浏览器后退出，不新开第二个服务，也不报端口错误；服务已经不在时（包括上次崩溃留下的旧文件），照常启动新服务。服务退出时删掉这个文件。
2. **页面显示服务状态**：页面上能看到「服务运行中」和「后台活动：已暂停 / 已开启」。本单后台没有任务，开启时也要如实说明暂时没有后台任务，不假装 Peter 在干活。服务退出或断开时沿用现有提示，并且不再显示后台在运行。
3. **暂停与恢复**：新增 `/pause` 和 `/resume` 命令（终端和网页共用 `run_chat` 的命令入口），页面上也给一个对应按钮。状态按角色保存在 `data/<角色>/` 下的本机文件，重启后保持原状态。**默认是暂停**，lan 第一次手动恢复后才算开启。这只是开关，本单不跑任何后台模型请求，不花钱。
4. **为 4B-2 留好的程序约束（只做最小一层，用测试证明，不加空接口）**：聊天和以后的后台活动共用同一个运行位，同一时间只有一个在调用模型或工具；用户发来消息时，后台活动在当前工具步骤结束后让位，不在步骤中间打断；暂停状态由程序检查，不靠提示词。测试里可以用假的后台任务验证，正式代码里不放任何会自己运行的后台任务。
5. **调查并写进施工结果**（只调查，不实现）：Windows 上不留命令行窗口运行（例如 `pythonw`）、托盘、开机自启动、睡眠唤醒后定时行为，各自是否值得做、成熟库和许可证。结论给 lan 决定。
6. 关掉命令行窗口仍会直接结束服务，这一点在页面断开提示和 README 里讲清楚；推荐用 `/quit` 退出。

不改：聊天、`send_message`、流式、工具、审批、记忆、预算和 `/cost` 的行为，以及所有已有数据。

## 验收步骤（Windows）

1. 双击 `start-web.bat`，和 Peter 聊一句。关掉浏览器页面，等一会儿，确认命令行窗口里的服务还在。
2. 再双击 `start-web.bat`，确认浏览器直接打开同一个聊天，刚才的消息都在，没有报端口被占用，也没有出现第二个命令行窗口里的新服务。
3. 页面上看到「服务运行中」「后台活动：已暂停」。输入 `/resume`（或点按钮），显示变成已开启并说明暂时没有后台任务；`/cost` 没有新增花费。
4. 用 `/quit` 退出再重新启动，确认后台活动状态和退出前一样；再 `/pause`，重启后仍是暂停。
5. 用 `/quit` 退出后，开着的页面显示 Peter 已退出，不再显示后台在运行；直接关命令行窗口时，页面显示断开提示。
6. 聊天、多条短消息、lab、文件审批、记忆照常。
