# 工单 200：外部 MCP 服务启动等待放宽到 60 秒

## 背景
通过 `cmd` → `npx` → `mcp-remote` 连接远程 MCP（例如花园论坛）时，单独启动就要约 8 秒。VEIL 启动握手只给 10 秒（界面侧的看门狗 12 秒），稍慢就失败；失败提示是看不懂的“unhandled errors in a TaskGroup”。Lan 重启后、改权限后保存都会连接失败，需要手动停用再启用。

## 改动
- 外部 MCP 服务启动并读取工具列表的等待上限由 10 秒改为 60 秒；界面看门狗同步为 65 秒。
- 启动超时的提示改为“MCP 服务启动超时（超过 60 秒），请稍后点停用再启用重试。”。
- 工具调用超时（20 秒）和连接后的探测不变。

## 验收（Lan）
update.bat 后重启 VEIL：MCP 页的 `galatea_garden` 自己显示“已连接”，不需要手动停用再启用。改权限（每次询问 ↔ 直接调用）并保存后也自动连接成功。
