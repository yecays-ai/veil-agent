# 工单 071：网页与 Electron 共用图片聊天

## 目标

Lan 可以在网页聊天和现有 Electron 聊天窗口中选择、粘贴或拖入图片，发送前预览并取消，发送后看到与网页一致的图片气泡；图片和历史仍由同一个本机 Agent 保存。

## 当前状态

原网页只有文字输入，Electron 只是安全加载同一个 `web/index.html`。本单使用原生浏览器文件选择、剪贴板和拖放事件，不引入第三方图片组件；`web_agent.py` 通过现有本机 token 鉴权上传和读取 `data/<character>/media/`，`chat.jsonl` 继续是唯一聊天记录。没有找到可直接复用且无需新增依赖的合适实现。

## 验收步骤

1. 在网页聊天中选择一张虚构图片，确认发送前有缩略图且可以取消；再用粘贴或拖入方式发送，确认图片气泡出现。
2. 收起/展开 Electron 聊天窗口，刷新并退出重开桌面壳，确认同一张图片历史仍显示；确认 Electron 聊天没有额外媒体目录。
3. 确认图片选择、粘贴和拖入仍在同一个聊天窗口内完成，未出现额外权限提示或文件访问窗口。
