# 工单 005c：聊久了报"上下文太长"并退出（验收阻断）

## 现象（lan 在 Windows 真实使用，2026-10-19）

记忆保存、/memory、/forget、/restore 验收通过。继续聊时出现"本次上下文太长，未发送；请减少 history_rounds 或缩短输入。"，随后程序退出（"Press any key to continue"）。

## 原因

- 每次请求按 UTF-8 字节数保守估算输入（字节数是 token 数的上限），超过 `max_input_tokens`（32768）就拒绝。带 20 轮长回复、人设和记忆时，字节数很容易超过 32 KB，实际 token 远没到。
- 这个拒绝是 `UserError`，会结束整个程序，并且每次启动都会再读回同样的 20 轮，所以聊天会一直停在这里。

## 修复

- 超出时只在这一次请求里丢掉最旧的整轮原文，直到放得下；`chat.jsonl` 完整保留，长期记忆照常召回。每个会话提示一次"这次只带了最近 N 轮原文"。
- 人设、记忆加这条输入本身超过边界时，才提示太长并且不保存这条输入；程序不再退出，缩短后重发。
- 估算方法和预算预留不变，仍然是字节数、预留整个 `max_input_tokens`。
