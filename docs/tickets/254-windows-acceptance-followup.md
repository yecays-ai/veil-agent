# 工单 254：Windows 启动与工作台实机验收补丁

## 目标

Lan 从桌面启动 Peter 并运行普通 OpenCode 项目测试时，不再看到后台命令窗口或处理误触发的审批。

## 当前状态

PR #309 已合入并修复快捷方式、filesystem MCP 与 `/work` 审批映射，但 Windows 复验仍确认 Ombre 的两层控制台 Python 进程会弹出黑窗；Galatea 等 `.cmd/.bat` MCP 入口也可能退回普通 CMD。后续补丁统一使用现有无窗口启动能力，不引入新的桌面入口或权限系统。

## 验收步骤

1. 更新后从桌面 `Start Desktop` 启动并点击桌宠，确认全过程不出现黑色命令窗口，聊天仍正常打开。
2. 在已有 `calculator-test` 项目运行 `python3 test_calculator.py`，确认不出现审批；需要审批的项目外或高风险操作仍出现审批，命中硬拒绝规则的命令直接拒绝。
3. 完全退出并重新启动一次，确认文件工具、记忆和停止功能仍正常。
