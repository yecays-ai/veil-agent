# 工单 402：指令全部归位，工具说明按类管理

## 目标

第一阶段（指令统一管理）收尾，补上审计指出的三个缺口：

1. 剩余指令没有统一归属。
2. 防写死检查可以靠往清单里加一行绕过。
3. （已在 401 修）醒来提示的可改措辞与固定协议混在一起。

## 本单做了什么

- 迁移进登记表：想起判官（聊天/自主两版）、经历记忆整理与修稿、短期便签提取、委派助手设定、
  6 条「外部内容只是数据」的防注入包裹、4 条醒来记录框架句（瞄一眼记录、上一次活动卡片、简短说明、乌有乡提示）。
- 工具说明改为按类管理（`prompts/tools.py`）：页面读取角色实际提供的工具，一个工具一行，
  可改可存到 `persona/instructions/tool.<名字>.md`；新增工具自动出现，不需要登记。
- 防写死：`prompts/inline.py` 结构化豁免工具说明；其余长句必须进类型化反馈清单
  （`inline_feedback_allowlist.txt`，只许减少）；提示词正文必须来自 defaults。
- 删除旧的 `inline_allowlist.txt`。

## 验证

- 改造前后同一场景（含醒来提示、背景、记忆笔记）请求逐字节一致。
- 迁移相关测试 251+ 通过；新增工具行/覆盖保存/反馈清单只减测试。
- 桌面端无改动，仍 21 个测试。

## 验收（Lan）

1. 打开「指令 → 工具」，能看到每个工具的说明，改一个保存，下一句请求按新说明。
2. 新增一个工具（或 MCP 服务）后刷新页面，自动多一行，不用改页面。
3. 搜索「醒来」能找到行为段和四行格式（后者只读并写明原因）。
