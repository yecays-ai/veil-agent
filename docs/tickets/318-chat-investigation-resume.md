# 工单 318：普通聊天调查续接

## 目标

Peter 的普通聊天调查被步骤、上下文、预算或重启打断后，Lan 说“继续”可从已确认的证据安全续接。

## 当前状态

普通聊天只保留工具活动摘要，不能作为调查计划或副作用恢复依据。本工单在角色数据目录保存一条最小检查点：原始目标、真实工具状态和有限证据；继续时重新规划，仍走原 Budget、权限和审批入口。

## 验收步骤

1. 将普通聊天工具步骤临时设为 3，发起需要至少四步的公开调查；确认中断时说明已完成证据、停止原因和未完成部分。
2. 只发“继续刚才的调查”，再重启 Peter 后重复；确认已完成且仍新的只读步骤没有重做，过期证据只重查对应来源。
3. 在调查中拒绝或停止一个需审批的动作后继续；确认它不会自行重放，费用和审批仍按当前规则执行。
