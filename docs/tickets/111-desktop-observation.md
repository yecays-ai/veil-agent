# 111 Peter 能只读观察 Windows 桌面

## 目标

Lan 可以自然地问 Peter 电脑上开着什么、指定窗口显示什么。Peter 使用真实窗口元数据和 UI Automation；界面树不够时，用现有视觉模型读取当前目标窗口截图。整个过程不改变焦点、窗口、剪贴板或文件。

### 三个价值问题

1. Lan 可以直接问 Peter 当前开着哪些应用、记事本写了什么、Codex 现在显示什么；这是此前无法完成的实时桌面观察。
2. 读文件只能看到保存后的内容，不能知道未保存文字、窗口状态、按钮提示或当前报错；桌面观察补上这些实时界面信息。
3. Lan 不用读代码即可通过并排打开应用、记事本测试文字、UIA 不足的界面、Codex 窗口、持续操作电脑和活动记录来验收，步骤如下。

## 当前状态

实现已在独立分支 `ticket/111-desktop-observation` 完成并通过针对性自动检查，PR 待审查，远端检查状态待确认。模拟窗口和现有工具循环测试通过；Lan 的 Windows 实机体验尚未进行，不能以自动测试代替验收。

## 复用

- 复用 Windows 依赖 `uiautomation==2.0.29` 发现顶层窗口、读取控件，并通过现有 `CaptureToImage` 回退截图；没有引入桌面自动化框架。
- 视觉图片以当前 Chat 模型请求的图片消息附带，复用 Peter 已有的图片理解链路。截图使用后不进入 `chat.jsonl`、`tools.jsonl`、长期记忆或附件存储。
- 聊天和自主活动都通过现有 `FilesystemTools`、工具循环、角色权限与同一个预算；不增加 Agent、调度器或预算池。
- QQ 适配器原有 UIA/焦点/剪贴板工作与新观察工具共用桌面互斥锁。

## 改动

1. 新增 `windows_list`、`windows_foreground` 与 `windows_observe` 三个只读工具。窗口 ID 绑定到进程路径、进程启动时间和窗口句柄；观察时重新枚举并精确核对 ID，不按标题选择。
2. UIA 最多读取 120 个控件、8 层深度，结果最多 8 KiB；每次 UIA 搜索最多 2 秒，单项工具最多 8 秒。只读取可见控件名称、类型、文本和有限只读状态。
3. UIA 为空或信息稀少时，最多将一张当前前台目标窗口截图加入本次模型请求。限制 8 百万像素和 5 MiB；不激活后台窗口、不使用剪贴板。临时截图文件在读取后立即删除。
4. 拒绝凭据/安全进程、敏感标题、密码字段和敏感控件标签；检查锁屏与安全桌面；把标题、控件内容和图像识别内容标为不可信数据。
5. 活动账本记录工具开始、结束状态、应用摘要和控件数量，不记录窗口标题、控件文本或图片。
6. 仅 Peter 的角色配置启用此项；其他角色默认关闭。权限新增为明确的 `desktop_read`，不添加 shell、点击、输入或文件修改能力。

- `tests.test_chat.ChatTests` 67 项通过；`ToolPolicyTests`、`ToolLoopTests`、`MultiMessageTests` 合计 51 项通过、2 项因账户不支持符号链接跳过；QQ 与活动账本测试 19 项通过。
- 相关 Python 模块编译和 `git diff --check` 通过。另有 2 项 Chat SDK/密钥测试因当前环境缺少 `httpx2`、`dotenv` 未运行；MCP 文件服务真实子进程启动测试因 `npx` 引导等待未完成。

## 费用与权限

没有新增第三方依赖、模型供应商或独立费用项。视觉截图会按当前视觉模型的图片输入规则计入现有请求与预算；分辨率和模型价格决定具体用量。没有新增预算池。权限只增加 Peter 角色内的普通窗口只读观察；不授予任何窗口操作或文件写权限。

## 验收步骤（Lan 的 Windows 体验）

1. 同时打开至少两个应用，问 Peter“你看看我现在开着什么软件”，核对窗口列表及同名窗口区分。
2. 在记事本输入一段测试文字，请 Peter 读取，核对内容准确。
3. 使用一个 UIA 不能充分读取的界面，请 Peter 观察，确认视觉结果来自真实截图。
4. 打开 Codex，请 Peter 描述当前界面可见状态；只检查当前状态，不以一次截图判断是否长期卡死。
5. Lan 继续操作其他软件时请求观察，确认没有抢焦点、点击、改动窗口布局、剪贴板或文件。
6. 在活动窗口核对观察开始、成功或失败记录；确认没有界面文本或截图写进活动账本、聊天历史或记忆。
7. 关闭目标窗口或请求观察不可访问窗口，确认 Peter 明确报告失败而不编造内容。
8. 尝试普通聊天请求执行点击、输入或文件修改，确认本工单没有提供这些权限。
