# 工单 011：成长日记安全追加

## 目标

Peter 能在终端一次授权后，跨重启持续向工作区的 `growth-journal.md` 末尾追加日期日记，旧内容保持原样；其他文件每次追加仍需确认。

## 当前状态

`write_file` 仅独占新建，官方 filesystem MCP 服务当前没有独立的 append 工具；它的 `write_file` 可覆盖，不能用于本权限。复用现有 MCP 工具循环、工作区路径校验及角色数据目录；追加使用操作系统 `O_APPEND` 且不带 `O_CREAT`，授权保存到角色数据目录，并绑定文件路径与身份。持续授权工具仅对配置中的 `growth-journal.md` 生效。PR #21 尚待合并，011 提交前更新到合并后的 main。

## 验收步骤

1. 在 Windows 聊天中请 Peter 对已有 `growth-journal.md` 申请持续追加，终端确认一次；随后让他追加第二篇日期日记，确认第一篇未变、第二篇完整在末尾。
2. 重启后再追加一篇，确认无需再次确认；要求修改或删除旧篇，确认程序拒绝。
3. 要求向另一个工作区文件追加，确认终端重新征求同意；工作区外路径始终拒绝。
