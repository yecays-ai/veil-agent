# 工单 037：修复主动消息后的记忆重启失败

## 目标

Peter 在聊天后追加主动消息并重启服务时，记忆调度正常启动，原聊天和记忆保持完整。

## 当前状态

最新 main `96a91d9` 可用虚构数据复现：每个用户轮次若有多条助手消息，轮次数会被错误排除，可能小于已持久化游标；Extract 与 Native 模式重启都会报记忆调度记录损坏。问题位于 `memory_agent.py` 的轮次统计，相关持久化回归测试位于 `tests/test_memory.py`。已查询 GitHub 上的记忆游标和对话分组实现，没有可直接复用的实现能兼容本项目现有 JSONL 格式，因此保留本地状态格式，只修复轮次分组。

## 验收步骤（Lan 在 Windows 上做）

1. 正常聊天后让 Peter 自然产生主动消息，退出并重新打开服务和网页。
2. 确认此前聊天、主动消息和顺序都保留，记忆系统正常启动且可继续聊天与记忆召回。
3. 无需删除或重建任何记忆状态，也无需为验收额外消费或人为制造故障。
