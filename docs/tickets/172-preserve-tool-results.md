# 工单 172：保留中文工具结果正文

## 目标

Peter 能读取工具已经获取的中文桌面文件名、记忆目录与正文，同时程序生成的状态提示继续使用英文。

## 当前状态

`veil_agent.py` 的 `model_tool_result()` 曾按中文字符和工具白名单将成功结果替换成英文成功提示。现已在工单 171 合并后的 `ticket/172-preserve-tool-results` 移除这项替换，并将明确的程序成功提示在生成处改为英文。小红书帖子和评论新增不可信内容包裹；既有 MCP、浏览器、Windows 桌面不可信内容包裹及工单 165 的长度控制保留。本修复复用现有结果传递机制，无需外部实现或新增依赖；Windows 体验仍待验收。

## 验收步骤

1. 在 Windows 上让 Peter 查看桌面列表，确认能说出真实中文文件名。
2. 让 Peter 查看记忆目录的真实编号和中文标题，再指定一条读取正文。
3. 用英文聊天执行普通工具，确认程序提示保持英文；检查文件审批、工具活动、Lab 和普通聊天正常。
