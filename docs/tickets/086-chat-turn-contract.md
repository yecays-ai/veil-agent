# 目标

同一条用户消息触发多条 assistant 回复时，聊天上下文和自动记忆完整保留这一轮的所有回复，并且仍只计一个用户轮次。

# 当前状态

`Chat.recent` 已把连续 assistant 事件保留在用户轮次中；`Memory.turns` 之前只保留第一条，导致记忆漏掉后续回复；请求编号和工具摘要也需要复用同一分组规则。文件读取后的记忆提取也只遮蔽单条回复。已查 GitHub 中的通用实现，没有找到能直接复用且适配 VEIL 本机聊天账本/记忆游标契约的库；按项目现有账本结构修正，不新增依赖。修改位于 `veil_agent.py`、`memory_agent.py` 和对应单测。

# 验收步骤

1. 在一轮中让 Peter 连续发送两条独立回复，重启后确认两条按原顺序保留，并用于后续上下文。
2. 完成四轮（其中一轮含多条 assistant 回复）后，确认自动记忆仍以四个用户轮次为批次；有文件读取的轮次不把 assistant 正文带入记忆提取。
