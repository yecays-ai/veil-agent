# 日常使用

> 桌面版与终端版共用同一套代码、同一份数据、同一把聊天锁；下面写的对话、命令、记忆、工具权限与预算口径在两种入口下一致，标明「仅桌面版」的界面与媒体操作只在桌面端提供。

## 聊天

- （仅桌面版）单击桌宠展开/收起聊天窗，按住拖动位置，右键打开菜单（尺寸、活动、退出桌面形象）。
- 消息支持多条分组、引用、重新生成、撤回、中途叫停；可以连发、插话，他也能选择已读不回或晚点回。
- （仅桌面版）语音：浏览器听写、按住说话、发送语音消息；回复可以带语音。
- （仅桌面版）图片：可发送图片，桌面会先缩放到入库上限内；原图最大 25 MB。

## 常用命令

| 命令 | 作用 |
| --- | --- |
| `/cost` | 今天/本月费用、待核对预留、聊天与自主分项、缓存命中率 |
| `/self` | 原样显示最近一次发给模型的「当前状态说明」（角色、模型、时间、记忆范围、能力边界） |
| `/memory` | 最近 20 条记忆的编号、时间、标题 |
| `/delete 编号` | 先显示这一条，再 `/delete 编号 确认` 才执行；删除不可恢复 |
| `/quit` | 退出（回复先落盘再显示） |

不进入聊天查花费：在项目目录运行 `.venv\Scripts\python.exe -m veil --cost`（根目录 `veil_agent.py` 兼容入口同样可用）。

## 记忆

记忆由本机 Brain（`data/<角色>/brain.db`）唯一保存：正文、版本、向量、事件、阶段、证据、引用、关系、来源、投影与审查记录都在同一个库。旧的 Ombre 实现已随 P3 物理卸载，历史文档只作归档，不是运行回退路径。

- 开局读一次重要记忆，每次发消息前按相关度检索；没有命中时明确告诉模型不要假装记得。
- 程序不自动删除记忆；pinned/importance 由程序控制写入和排序。
- 桌面「记忆」页可浏览、编辑、置顶、归档、恢复；「经历」页看事件故事与阶段；「健康」页做 H-1 ~ H-9 巡检。
- 换 Embedding 模型必须跑一次显式重建（`scripts/embedding_reindex.py`，默认 dry-run），否则旧记忆会停在「待索引」。

## 工具与权限

- **工作区文件工具**：只访问 `data/<角色>/workspace/`；Peter 可在其中新建、覆盖、编辑、移动与删除**自己的文件**，无需事先审批，程序会保留旧版本（`own-work-versions`）以便恢复。
- **桌面文件工具**：只读工具可列出、按精确文件名搜索并读取 Windows `Desktop`、`Documents`、`Downloads`、`Pictures` 中的普通文件（跳过隐藏、敏感或链接文件）；写入工具无需额外审批且无每日次数上限，可在 `Desktop`、`Documents`、`Pictures` 新建受限扩展名的文本文件，且只能改写或移走（移入 `lab/trash/`）Peter 自己创建且未被你修改过的文件，绝不修改、重命名或删除你自己的文件。
- **成长日记**：只能追加，不能覆盖或删除。
- **外部接入与确认边界**：独立浏览器 / 小红书（只读）、GitHub（只读）、网页检索、MCP 服务（按服务单独授权）、工作台项目外路径等由程序代码控制权限边界；需要你显式确认的操作（如 `/delete 编号 确认` 删记忆、冷备份 `--replace` 恢复、工作台敏感命令等）由程序强制校验，不靠提示词。
- **过程与记录**：每次工具调用在屏幕上显示一行，过程记录在 `data/<角色>/tools.jsonl`；`data/<角色>/chat.jsonl` 记录实际发送的用户消息与 assistant 消息（同一轮或自主唤醒期间可能包含多条 assistant 消息）。

## 预算与花费

- 所有角色共用一个总账；日/月双上限，可在「预算」页调整基础限额。
- 请求前按输入额度与最大输出预留，请求后按接口返回的用量结算；日/月按本机日期与请求开始时间归属。
- 失败或结果不确定的预留会保留（无法确定供应商是否扣费）；程序不自动重试。
- 价格是本机核算参数，不等于供应商账单；换模型或调价时请一并更新配置。

## 扩展通道

- **QQ 邮箱**（工单 098）：在 `.env` 填 `PETER_EMAIL_ADDRESS`、`PETER_EMAIL_AUTH_CODE`、`LAN_EMAIL_ADDRESS`，重启后 Peter 可以给你发邮件，你回信他会接上。每天最多 20 封。
- **QQ 消息**（工单 102）：像人一样操作你电脑上登录的 QQ 窗口，只在你不碰电脑且不在全屏看视频时读和发。每天最多 100 条。
- **独立浏览器 / 小红书**：使用独立临时浏览器目录，不碰你正在用的窗口；小红书只读推荐、搜索与详情，发布/评论/关注明确拒绝。
- **MCP**：在 MCP 页添加本地或远程服务，按服务单独授权与停用。

## 备份与恢复

```powershell
.venv\Scripts\python.exe -m veil.system.backup_restore create --destination "X:\VEIL-backups"
.venv\Scripts\python.exe -m veil.system.backup_restore verify   --backup "X:\VEIL-backups\<时间戳>"
.venv\Scripts\python.exe -m veil.system.backup_restore restore  --backup "X:\VEIL-backups\<时间戳>" --target "D:\VEIL-recovery" --replace
```

（根目录 `backup_restore.py` 过渡兼容入口同样支持上述子命令。）

备份含明文人设、记忆和可能含密钥的 `.env`，程序不加密也不上传：只放在加密磁盘或受控离线介质，不放云同步目录。恢复前会校验每个文件的哈希；`--replace` 需要输入 `RESTORE`，原数据整体移到 `*.before-restore-*`。

完整步骤与回滚见 [`backup-and-restore.md`](backup-and-restore.md)；账本与损坏修复见 [`data-repair-and-ledger.md`](data-repair-and-ledger.md)。

## 多角色

建立 `characters/<id>/character.toml` 与自己的本机人设，用 `start.bat --character <id>` 启动。人设、历史、记忆按角色分开；费用共用一个总账；同一时间只能开一个聊天窗口。
